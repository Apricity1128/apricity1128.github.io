### C. Permutation Inversions

> 有一个未知的长为 $n$ 的排列，现给你 $m$ 条限制，每条给定若干个数，表示一个未知序列的偏序关系。
>
> 你要输出满足限制的，**逆序对**数量最少的原序列。没有输出 $-1$。$n,m\le 10^6$。

此类偏序关系可以直接建图，如果 $a_i<a_j$ 则建一条 $i\to j$ 的有向边，那么有答案当且仅当原图是一张DAG。

逆序对尽可能少，即为尽量顺序开始填数，想到利用小根堆维实现拓扑排序即可。

### M. 中位数为 X 【范德蒙德卷积】【组合数学】

> 给定序列 $a$，数字 $x$，求有多少 $a$ 的可重子集满足中位数为 $x$，下标不同算作一种方案。



对于偶数的情况，考虑中位数定义 $M=\frac{a_{n/2}+a_{n/2+1}}{2}$，枚举 $a_{n/2}$ 的**下标**（一定选 $i$，且不会选两个中位数之间相邻的，用来保证不重不漏），即可得到 $a_{n/2+1}$ 的**值**。
$$
\sum_{i=1}^n\sum_{num=1}^i\binom{i}{num}(\binom{sum2}{num}-\binom{sum3}{num})
$$
我完全不会范德蒙德卷积

**注意：范德蒙德卷积的下标是从 $0$ 开始！**
$$
\sum_{i=0}\binom{n}{i}\binom{m}{k-i}=\binom{n+m}{k}
$$
等价于枚举前 $n$ 个物品中选几个，后 $m$ 个物品中选剩下 $k-i$ 个。

因此原式可以推导为：
$$
\sum_{i=1}^n\sum_{num=0}^{i-1}\binom{i-1}{num}\binom{sum2}{sum2-(num+1)}=\sum\binom{i-1+sum2}{sum2-1}
$$

具体的，其中 $sum2$ 为包含 $a_{n/2+1}$ 及之后的数字个数，注意这里不需考虑算重的情况，因为枚举 $i$​ 作为位置已经不重了。

对于奇数的情况，考虑枚举 $a_i=x$ 的所有 $i$，
$$
\sum_i \sum_{j=0}^{\min (i-1,n-i)}\binom{i-1}{j}\binom{n-i}{j}\\=\sum _{i}\sum_{j}\binom{i-1}{j}\binom{n-i}{n-i-j}\\=\sum_i\binom{n-1}{n-i}
$$

## F. 按位与路径 【bit】

> 有一张无向图，初始没有边，支持以下操作：
>
> - 在某两个点之间加一条带权边。
> - 查询某两个点之间路径按位与的最大值。
>
> $n\le 10^3,q\le 10^6,w\le 2^{12}$。

感觉挺难的题。

如果按位考虑 $u\to v$ 的可达性的话，会出现一种情况，也就是 $u\to v$ 在最高位能连通的路径，可能完全不同于 $u\to v$ 在次高位能连通的路径。

对此我们的解决方案是，记录 $S(m)$ 表示 $m$ 的所有**超集**的可达性。

那么我们便可以按位考虑，这样即是一种变向的**从小到大**枚举，而非二分或传统的按位考虑。

问题在于如何维护可达性，考虑加入一条 $w$ 边，枚举所有子集，如果已经连通了就不再继续枚举，这个过程可以用递归方便实现。

### L. 暴击【DP去后效性】

> 给定 $n$ 件物品，有价格，暴击概率，暴击效果。
>
> 当多件装备同时暴击时，只有暴击效果最高的会生效。
>
> 求 $m$ 元最终能得到的最高暴击效果期望。$n,m\le 10^3$。

正常思路是将暴击效果降序排序，然后计算式子类似：
$$
p_1v_1+(1-p_1)p_2v2+(1-p_1)(1-p_2)p_3v_3....
$$
这样做是不好处理DP后效性的，如果我们按照暴击效果升序排序，则有经典 0/1背包：
$$
f_{i,j}=\max\{ f_{i-1,j},(1-p_i)\times f_{i-1,j-w_i}+p_i\times v_i\}
$$
别忘了 0/1 背包别越界，需要特判：

```cpp
for(int i=1;i<=n;i++) {
    for(int j=1;j<=m;j++) {
        if(j>=a[i].w)f[i][j]=max(f[i-1][j],f[i-1][j-a[i].w]*(1-a[i].p)+a[i].p*a[i].v);
        else f[i][j]=f[i-1][j];
        if(i==n) ans=max(ans,f[i][j]);
    }
}
```

还有需要回忆 `double` 和 `long double` 的用法

1. 算法竞赛一般无需使用 long double （18位），只需使用double（15位）

2. **注意 `-0.00`**：计算结果可能是一个极小的负数，格式化后输出 `-0.00`，而期望是 `0.00`。可在输出前加一个极小的 `eps` 修正。

3. **推荐使用 `printf`**：`printf("%.10f\n", ans);`。它格式化行为稳定，且 `double` 用 `%f`，`long double` 用 `%Lf`。

4. 用**乘法**代替除法比较，转换为交叉相乘，可能会溢出（用 `__int128` 避免）

5. **eps**容差定义（包括重定义相等比较，使用`fabs`函数）

   ```cpp
   const double eps = 1e-9;
   
   double maxWithEps(double a, double b) {
       if (a - b > eps) return a;   // a 明显更大
       if (b - a > eps) return b;   // b 明显更大
       return a;                    // 认为相等，返回任意一个（这里返回 a）
   }
   ```





# 武汉邀请赛

### I.宾果游戏

> 给定 $n,k$，构造一个 $n\times n$ 的表格并填入 $1\sim n^2$ 的数，使得 $k$ 为最小的宾果整数。
>
> 如果满足以下两个条件中的至少一个，我们称整数 $x$​  为该网格的一个“宾果整数”（bingo integer）：
>
> - 至少存在一行，该行所有单元格中的整数都小于或等于$x$ 。
> - 至少存在一列，该列所有单元格中的整数都小于或等于$x$ 。

构造题，考虑把 $k$ 放在 $(n,n)$ 右下角。

把最大的若干个数放在对角线上，这样就把这些行和列都废了，然后再把最小的数都放在最后一行和最后一列，剩下的随便填中间的数，这样如果能满足最后一行和最后一列的限制，那么就有解，并构造成功。

###  L. 子序列

> 求最长的子序列满足最小值+最大值=二倍的中位数。
>
> $n\le 10^3$。

显然先排序，直接枚举最小值和中位数，然后最大值可以直接计算得到。

如果用map等找最大值所在的最远位置会带 $\log$，因此用双指针扫即可。

答案分类讨论是奇数还是偶数，奇数为 $\min(j-i+1,k-j)*2+1$，偶数为 $\min(j-i,k-j)*2$。

> 有 $n$ 组物品，每组有 $a_i$ 个，每个重量是 $2^{b_i}$，

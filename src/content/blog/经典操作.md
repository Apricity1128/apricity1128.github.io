# 使用说明

这是一本为 ICPC / CCPC 现场赛准备的**纸质速查手册**，不是入门教程。它假设你已经系统学过一遍相关算法，赛前用它回忆“这题该往哪个方向想”，赛中用它快速核对写法和边界。

全书按主题分为五部分知识点、经典操作、注意事项和代码模板。每个知识点固定给出：**算法思路、核心代码、经典例题、经典套路、易错点**。例题只保留题号、题意关键词和关键一步，不抄完整题面；真正的题面请在洛谷 / Codeforces 上检索。

# 第 1 部分 数据结构与树上技巧

本部分整理比赛中出现频率最高的“数据结构 + 树上维护”套路。重点是看到题面特征时能立刻想到对应工具，以及写模板时最容易错的边界。

## 1.1 bitset

**算法思路** `bitset<N>` 把 N 个 bit 压进 N/64 个 `unsigned long long`，一次 `<<`、`>>`、`&`、`|`、`^` 都是 O(N/64)。它最适合两类问题：一是**可达性/子集和**，二是**集合交并**。典型写法是 `f |= f << a[i]` 表示“选或不选 a[i]”；多重背包按二进制拆分后同样处理。遍历可用 GCC 的 `_Find_first()` / `_Find_next(x)`，比逐位检查快得多。

复杂度：单次位运算 O(N/64)，`count()` O(N/64)；空间 O(N/8) 字节。

**核心代码**

```cpp
const int MAXV = 200005;
bitset<MAXV> f;
int n, a[N];

void subset_sum() {
    f.reset();
    f[0] = 1;
    for (int i = 1; i <= n; i++) f |= f << a[i];
}

void iterate() {
    for (int x = f._Find_first(); x < MAXV; x = f._Find_next(x)) {
        // x 是一个可达和
    }
}
```

**经典例题**

- 【模板】P1537 弹珠：多重背包可达性，二进制拆分 + `bitset` 优化。
- 【进阶】P3674 小清新人渣的本愿：莫队维护值域 `bitset`，判断区间内是否存在差/和为 x 的两数。
- 【进阶】CF 914F Substrings in a String：对每个字符开 `bitset`，按模式串逐位与。

**经典套路**

- 看到“选若干个数和为 S” → `f |= f << a[i]`。
- 看到“两个集合是否有交/并” → 两个 `bitset` 直接 `&` / `|`，再用 `any()`。
- 看到“区间内是否存在某个值” → 值域 `bitset` + 莫队/分块。
- 看到“带删除的可行性” → 线段树分治 + `bitset`，或退背包。
- 多重背包数量很大时，先二进制拆分，再 `bitset` 平移。

**易错点**

- `bitset<N>` 的 N 必须是编译期常量；按最大可能值开，不要按 n 开。
- `_Find_first()` 在没有 1 时返回 `N`，循环条件必须写 `x < N`。
- 左移超过 N 的位会被丢弃，答案上界要提前确认。
- `count()` 返回 `size_t`，和 `int` 比较时注意符号。

## 1.2 ST 表

**算法思路** 倍增预处理 `st[k][i]` 表示区间 `[i, i+2^k)` 的答案。把区间拆成两个长度为 `2^k` 的块，只要运算满足**可重复贡献**（max、min、gcd、and、or），就可以 O(1) 查询；不满足的（如 sum）不能用。查询时 `k = lg[r-l+1]`，答案是 `op(st[k][l], st[k][r-2^k+1])`。

复杂度：预处理 O(n log n)，单次查询 O(1)，空间 O(n log n)。

**核心代码**

```cpp
int n, a[N], lg[N], st[20][N];

void build() {
    lg[1] = 0;
    for (int i = 2; i <= n; i++) lg[i] = lg[i >> 1] + 1;
    for (int i = 1; i <= n; i++) st[0][i] = a[i];
    for (int k = 1; (1 << k) <= n; k++)
        for (int i = 1; i + (1 << k) - 1 <= n; i++)
            st[k][i] = max(st[k - 1][i], st[k - 1][i + (1 << (k - 1))]);
}

int query(int l, int r) {
    int k = lg[r - l + 1];
    return max(st[k][l], st[k][r - (1 << k) + 1]);
}
```

**经典例题**

- 【模板】P3865 【模板】ST 表：区间最大值。
- 【模板】P2880 Balanced Lineup：区间最大值与最小值之差。
- 【进阶】P1890 gcd 区间：gcd 也可重复贡献。
- 【进阶】CF 475D CGCDSSQ：固定右端点，gcd 只有 O(log V) 种，配合 ST 表/二分。

**经典套路**

- 看到“静态区间最值、gcd、按位与/或” → ST 表。
- 看到“找最远的满足某性质的右端点” → ST 表 + 二分。
- 看到“区间 gcd 变化” → 固定一端，段数只有 O(log V)。
- 二维静态最值：每个方向做一遍 ST，查询 O(1)，空间 O(nm log n log m)。
- 需要求 LCA 时，也可用欧拉序 + ST 表。

**易错点**

- `lg[1] = 0`，`lg[0]` 不要用到；`lg[i] = lg[i >> 1] + 1`。
- 查询的两段可以重叠，但不能越界；`r - (1 << k) + 1` 要算对。
- `1 << k` 在 k 较大时用 `1LL << k`，或限制 k < 31。
- 不满足幂等性的运算不要套 ST 表。

## 1.3 主元素

**算法思路** 区间内出现次数严格大于一半的数最多一个，可以用**摩尔投票**在 O(n) 时间内找候选：维护 `cand` 和 `cnt`，相同则加一，不同则抵消。投票只能保证“如果有绝对众数，它一定是 cand”，**必须再扫一遍验证**。要求出现次数大于 n/k 的所有数时，维护 k-1 个候选；区间询问则可用线段树合并候选，或随机采样 + 二分计数。

复杂度：投票 O(n)，验证 O(n)；随机采样每次 O(log n) 查询出现次数。

**核心代码**

```cpp
int majority(vector<int>& a) {
    int cand = 0, cnt = 0;
    for (int x : a) {
        if (cnt == 0) cand = x, cnt = 1;
        else if (x == cand) cnt++;
        else cnt--;
    }
    cnt = 0;
    for (int x : a) if (x == cand) cnt++;
    return (cnt * 2 > (int)a.size()) ? cand : -1;
}
```

**经典例题**

- 【模板】P3567 [POI2014] KUR-Couriers：区间绝对众数，主席树/线段树合并。
- 【进阶】P4062 [Code+#1] Yazid 的新生舞会：区间众数计数，需要转化 + 数据结构。
- 【进阶】LeetCode 169 / 229：绝对众数与超过 n/3 的元素，投票法入门。

**经典套路**

- 看到“出现次数超过一半” → 摩尔投票，先找候选再验证。
- 看到“出现次数超过 n/k” → 维护 k-1 个候选，或随机采样。
- 区间绝对众数 → 线段树每个节点存 `(cand, cnt)`，合并时抵消。
- 只有候选还不够：用 `vector` 存每个值的位置，二分求真实出现次数。
- 随机化做法：随机抽 30 次，每次二分计数；错误概率极低。

**易错点**

- 忘记验证，把候选直接当答案。
- 严格大于一半用 `cnt * 2 > len`，不要写成 `>=`。
- 区间合并时候选相同要相加，不同要抵消，不能只保留一个。
- 随机采样要固定种子或使用高质量随机源，避免被构造数据卡。

## 1.4 单侧递归线段树（Segment Tree Beats）

**算法思路** 维护区间 `chmin/chmax` 与求和时，普通懒标记无法直接合并。Beats 的核心是记录**最大值 `mx`、严格次大值 `se`、最大值个数 `cnt`、区间和 `sum`**。若要把区间对 x 取 min：当 `x >= mx` 时无事发生；当 `se < x < mx` 时，只有最大值被改，可以直接把 `mx` 改成 x 并更新 `sum`；否则递归。因为每次递归都会让最大值种类减少，总复杂度 O((n+q) log n)（均摊）。区间取模、开方等“值变化次数有限”的操作也可用单侧递归：`mx < x` 时直接返回，否则递归到叶子。

复杂度：均摊 O((n+q) log n)；空间 O(n)。

**核心代码**

```cpp
const int M = 200005;
int mx[M << 2], se[M << 2], cnt[M << 2];
ll sum[M << 2];

// build：叶子 se = -INF, cnt = 1；普通区间合并 mx/se/cnt
void pushup(int p) {
    sum[p] = sum[p << 1] + sum[p << 1 | 1];
    mx[p] = max(mx[p << 1], mx[p << 1 | 1]);
    if (mx[p << 1] == mx[p << 1 | 1]) {
        cnt[p] = cnt[p << 1] + cnt[p << 1 | 1];
        se[p] = max(se[p << 1], se[p << 1 | 1]);
    } else if (mx[p << 1] > mx[p << 1 | 1]) {
        cnt[p] = cnt[p << 1];
        se[p] = max(se[p << 1], mx[p << 1 | 1]);
    } else {
        cnt[p] = cnt[p << 1 | 1];
        se[p] = max(mx[p << 1], se[p << 1 | 1]);
    }
}

void apply_chmin(int p, int x) {
    if (x >= mx[p]) return;
    sum[p] -= 1LL * (mx[p] - x) * cnt[p];
    mx[p] = x;
}

void pushdown(int p) {
    apply_chmin(p << 1, mx[p]);
    apply_chmin(p << 1 | 1, mx[p]);
}

void range_chmin(int p, int l, int r, int ql, int qr, int x) {
    if (x >= mx[p]) return;
    if (ql <= l && r <= qr && x > se[p]) { apply_chmin(p, x); return; }
    pushdown(p);
    int mid = (l + r) >> 1;
    if (ql <= mid) range_chmin(p << 1, l, mid, ql, qr, x);
    if (qr > mid) range_chmin(p << 1 | 1, mid + 1, r, ql, qr, x);
    pushup(p);
}
```

**经典例题**

- 【模板】P6242 【模板】线段树 3：区间加、区间取 min、区间求和、区间历史最大值。
- 【进阶】CF 438D The Child and Sequence：区间取模，单侧递归的经典应用。
- 【进阶】P4145 上帝造题的七分钟 2 / 花神游历各国：区间开方，值下降很快。

**经典套路**

- 看到“区间 chmin/chmax + 求和” → Beats，维护 `mx/se/cnt`。
- 看到“区间取模/开方，值只降不升” → 单侧递归，`mx < x` 直接返回。
- 看到“区间历史最值” → 在 Beats 上再加历史标记，注意标记合并顺序。
- 区间赋值 + 区间加同时存在时，先处理赋值标记，再处理加法标记。

**易错点**

- 叶子的 `se` 要设成 `-INF`，`cnt` 设成 1；否则 `x > se` 判断会错。
- `apply_chmin` 只改最大值，`sum` 的减量是 `(mx-x)*cnt`，不要乘整个区间长度。
- `pushdown` 必须先用父节点的 `mx` 去更新儿子，再递归。
- 区间取模时，`mx < x` 才能直接返回；等于 x 也要递归/处理。
- 历史最值标记的顺序很容易写反，建议单独写 `update_max` / `update_add`。

## 1.5 dsu on tree 与线段树合并

**算法思路** 两者都解决“子树内按颜色/权值统计”的问题，但侧重点不同。

- **dsu on tree（树上启发式合并）**：先求重儿子；递归轻儿子时不保留贡献，递归重儿子时保留，然后把轻儿子子树暴力加回来。每个点被暴力加入 O(log n) 次，总复杂度 O(n log n)。适合“每个子树询问一个全局计数”。
- **线段树合并**：对每个点开一棵动态开点权值线段树，合并两个儿子时递归合并节点。总复杂度 O(n log n)，空间 O(n log n)。适合“子树内第 k 大、颜色出现次数、方案合并”等需要保留值域结构的问题。

**核心代码**

```cpp
vector<int> g[N];
int siz[N], son[N], col[N], cnt[N], ans[N], best;

void dfs1(int u, int p) {
    siz[u] = 1;
    for (int v : g[u]) if (v != p) {
        dfs1(v, u);
        siz[u] += siz[v];
        if (siz[v] > siz[son[u]]) son[u] = v;
    }
}

void add(int u, int p, int val) {
    cnt[col[u]] += val;
    // 在这里更新当前答案，例如 best = max(best, cnt[col[u]]);
    for (int v : g[u]) if (v != p) add(v, u, val);
}

void dfs2(int u, int p, bool keep) {
    for (int v : g[u]) if (v != p && v != son[u]) dfs2(v, u, false);
    if (son[u]) dfs2(son[u], u, true);
    for (int v : g[u]) if (v != p && v != son[u]) add(v, u, 1);
    cnt[col[u]]++;
    // ans[u] = best;
    if (!keep) add(u, p, -1);
}
```

```cpp
const int M = 200005;
int lc[M * 40], rc[M * 40], sum[M * 40], rt[M], tot;

void pushup(int p) {
    sum[p] = sum[lc[p]] + sum[rc[p]];
}

void update(int &p, int l, int r, int x, int v) {
    if (!p) p = ++tot;
    if (l == r) { sum[p] += v; return; }
    int mid = (l + r) >> 1;
    if (x <= mid) update(lc[p], l, mid, x, v);
    else update(rc[p], mid + 1, r, x, v);
    pushup(p);
}

int merge(int a, int b, int l, int r) {
    if (!a || !b) return a | b;
    if (l == r) { sum[a] += sum[b]; return a; }
    int mid = (l + r) >> 1;
    lc[a] = merge(lc[a], lc[b], l, mid);
    rc[a] = merge(rc[a], rc[b], mid + 1, r);
    pushup(a);
    return a;
}
```

- 【模板】P4556 [Vani 有约会] 雨天的尾巴：树上差分 + 线段树合并。

**经典套路**

- 看到“每个子树询问颜色出现次数/众数” → dsu on tree。
- 看到“每个点一棵权值线段树，子树信息合并” → 线段树合并。
- 看到“合并两个集合，按大小启发式” → 小并大，复杂度 O(n log n)。
- 树上差分：路径 `(u,v)` 加一 → `d[u]++`、`d[v]++`、`d[lca]--`、`d[fa[lca]]--`，最后线段树合并。
- 线段树合并时，若只关心答案，可以在 merge 过程中顺便统计逆序对/最大值。

**易错点**

- dsu on tree 的 `add(u,p,val)` 必须遍历**整棵子树**，不要跳过重儿子；跳过重儿子的逻辑只在 `dfs2` 里。
- 清空时用 `add(u,p,-1)`，不要 `memset` 整棵子树。
- 线段树合并后，`b` 的节点不再使用，但不要提前清空，避免影响其他合并。
- 动态开点数组大小是 `n log V`，按 `N * 40` 开，注意内存。
- 多测时清空 `tot`、`rt`、`lc/rc/sum`。

## 1.6 笛卡尔树 + 单调栈

**算法思路** 笛卡尔树满足：中序遍历是原序列，每个点的权值小于（或大于）其子树。用单调栈可以 O(n) 建树：维护右链，遇到更小的值就弹出，把最后一个弹出的点作为左儿子，当前点挂在栈顶的右儿子上。笛卡尔树把“区间最值分治”变成“树上 LCA/子树问题”。单调栈本身可以求每个数左右第一个更小/更大的位置，是最大矩形、区间贡献题的通用工具。

复杂度：建树 O(n)，每个元素进出栈一次；空间 O(n)。

**核心代码**

```cpp
int a[N], ls[N], rs[N], st[N];

void build_cartesian(int n) {
    int top = 0;
    for (int i = 1; i <= n; i++) {
        int last = 0;
        while (top && a[st[top]] > a[i]) last = st[top--];
        ls[i] = last;
        if (top) rs[st[top]] = i;
        st[++top] = i;
    }
    // 根是 st[1]
}

int l[N], r[N];

void get_range(int n) {
    int top = 0;
    for (int i = 1; i <= n; i++) {
        while (top && a[st[top]] >= a[i]) top--;
        l[i] = top ? st[top] : 0;
        st[++top] = i;
    }
    top = 0;
    for (int i = n; i >= 1; i--) {
        while (top && a[st[top]] > a[i]) top--;
        r[i] = top ? st[top] : n + 1;
        st[++top] = i;
    }
}
```

**经典例题**

- 【模板】P5854 【模板】笛卡尔树：输出左右儿子。
- 【模板】P4147 玉蟾宫：最大全 1 矩形，单调栈。
- 【进阶】P2422 良好的感觉：区间最小值 × 区间和，单调栈 + 前缀和。
- 【进阶】CF 1748E Yet Another Array Counting Problem：笛卡尔树 + 树形 DP。

**经典套路**

- 看到“每个数作为最小值能扩展多远” → 左右第一个更小，`a[i] * (r[i]-l[i]-1)`。
- 看到“区间最值分治” → 建笛卡尔树，递归左右子树。
- 看到“最大矩形/最大子矩阵” → 对每一行做单调栈。
- 笛卡尔树上 `lca(u,v)` 就是区间 `[u,v]` 的最值位置。
- 相等元素要统一方向（`>=` 或 `>`），避免区间算重。

**易错点**

- 单调栈里存的是**下标**，比较的是 `a[st[top]]`。
- 左闭右开/闭区间要统一：`l[i]` 是第一个更小位置，`r[i]` 是第一个更小或相等位置。
- 笛卡尔树根不是 1，而是建完后栈底 `st[1]`。
- 最大矩形要开 `long long`，`a[i] * (r-l-1)` 可能超 int。
- 多测时清空 `ls/rs/st`。


# 第 2 部分 图论与树

图论题的关键通常不是模板本身，而是**建模**：把限制翻译成边、把状态翻译成点、把“最大边最小”翻译成重构树。本部分按“连通性 → 路径 → 生成树 → 树上结构”的顺序整理。

## 2.1 tarjan

**算法思路** Tarjan 用 `dfn`（访问时间）和 `low`（子树内能回到的最早时间）刻画连通性。不同问题只改变“栈里放什么”和“判定条件”：

- **有向图 SCC**：维护一个栈，遇到未访问点递归；遇到栈内点用 `dfn[v]` 更新 `low[u]`；`low[u] == dfn[u]` 时弹栈到 u，得到一个 SCC。
- **无向图割边**：`low[v] > dfn[u]` 时边 `(u,v)` 是桥；**割点**：`low[v] >= dfn[u]`，且根节点要特判“搜索子树个数 > 1”。
- **点双/边双**：点双用栈存边/点，割点会在多个点双中；边双把桥删掉后剩下的连通块。
- **缩点**：SCC 编号后建 DAG，按 SCC 编号倒序即为拓扑序。

复杂度：O(n + m)。

**核心代码**

```cpp
vector<int> g[N];
int dfn[N], low[N], tim, st[N], top, scc[N], sccnt;
bool in[N];

void tarjan(int u) {
    dfn[u] = low[u] = ++tim;
    st[++top] = u;
    in[u] = true;
    for (int v : g[u]) {
        if (!dfn[v]) {
            tarjan(v);
            low[u] = min(low[u], low[v]);
        } else if (in[v]) {
            low[u] = min(low[u], dfn[v]);
        }
    }
    if (low[u] == dfn[u]) {
        ++sccnt;
        int x;
        do {
            x = st[top--];
            in[x] = false;
            scc[x] = sccnt;
        } while (x != u);
    }
}
```

```cpp
int dfn[N], low[N], tim;
bool bridge[N << 1], cut[N];

// 邻接表用附录 A 的 head/e，边从 2 开始编号
void tarjan(int u, int in_edge) {
    dfn[u] = low[u] = ++tim;
    int child = 0;
    for (int i = head[u]; i; i = e[i].nxt) {
        int v = e[i].to;
        if (!dfn[v]) {
            ++child;
            tarjan(v, i);
            low[u] = min(low[u], low[v]);
            if (low[v] > dfn[u]) bridge[i] = bridge[i ^ 1] = true;
            if (low[v] >= dfn[u]) cut[u] = true;
        } else if (i != (in_edge ^ 1)) {
            low[u] = min(low[u], dfn[v]);
        }
    }
    if (in_edge == 0 && child == 1) cut[u] = false;
}
```

- 【模板】P3387 【模板】缩点：SCC 缩点 + DAG 上最长路。
- 【模板】P3388 【模板】割点（割顶）：割点判定与根特判。
- 【模板】P8435 【模板】点双连通分量 / P8436 【模板】边双连通分量。
- 【进阶】P2341 [HAOI2006] 受欢迎的牛：缩点后出度为 0 的 SCC 唯一。

**经典套路**

- 看到“有向图强连通/缩点后 DP” → Tarjan SCC。
- 看到“删掉一个点/边是否连通” → 割点/桥。
- 看到“环上问题” → 点双/边双缩点，圆方树。
- 看到“有向图可达性” → SCC 缩点 + DAG 拓扑/ bitset。
- 缩点后建新图时，重边要排序去重；SCC 编号倒序就是拓扑序。

**易错点**

- 有向图的 `low` 只能用**栈内**点的 `dfn` 更新；无向图用 `dfn` 更新并跳过反向边。
- 无向图重边：必须用边编号判断反向边，不能用父节点。
- 割点根节点：只有一棵搜索子树时不是割点。
- 点双出栈只能出到 `v`，不能出到 `u`；割点属于多个点双。
- 多测清空 `dfn/low/tim/top/sccnt` 和邻接表。

## 2.2 2-SAT

**算法思路** 每个变量 x 拆成两个点：`x` 表示真，`¬x` 表示假。子句 `(a ∨ b)` 等价于两条蕴含边：`¬a → b`、`¬b → a`。建图后跑 Tarjan SCC：

- 若 `x` 与 `¬x` 在同一个 SCC，无解；
- 否则 `scc[x] < scc[¬x]` 时取真（Tarjan 编号是反拓扑序，取拓扑序靠后的那个）。

用 `2*x` 和 `2*x+1` 表示真/假，取反就是 `^1`，比 `x` 与 `x+n` 更不容易写错。

复杂度：O(n + m)。

**核心代码**

```cpp
int n, m;
vector<int> g[N << 1];
int dfn[N << 1], low[N << 1], tim, st[N << 1], top, scc[N << 1], sccnt;
bool in[N << 1];

int id(int x, bool v) { return 2 * x + (v ? 0 : 1); }

void tarjan(int u) {
    dfn[u] = low[u] = ++tim;
    st[++top] = u;
    in[u] = true;
    for (int v : g[u]) {
        if (!dfn[v]) {
            tarjan(v);
            low[u] = min(low[u], low[v]);
        } else if (in[v]) {
            low[u] = min(low[u], dfn[v]);
        }
    }
    if (low[u] == dfn[u]) {
        ++sccnt;
        int x;
        do {
            x = st[top--];
            in[x] = false;
            scc[x] = sccnt;
        } while (x != u);
    }
}

void add_clause(int x, bool bx, int y, bool by) {
    int a = id(x, bx), b = id(y, by);
    g[a ^ 1].push_back(b);
    g[b ^ 1].push_back(a);
}

bool solve() {
    for (int i = 1; i <= 2 * n; i++) if (!dfn[i]) tarjan(i);
    for (int i = 1; i <= n; i++) if (scc[2 * i] == scc[2 * i + 1]) return false;
    return true;
}
```

**经典例题**

- 【模板】P4782 【模板】2-SAT 问题：输出任意一组解。
- 【模板】P4171 [JSOI2010] 满汉全席：每种食材选满/汉。
- 【进阶】CF 776D The Door Problem：门的状态与开关的奇偶性。
- 【进阶】P3007 [USACO11JAN] The Continental Cowngress G：2-SAT + 方案判定。

**经典套路**

- 看到“每个变量二选一，若干限制” → 2-SAT。
- 看到“区间/前缀限制” → 线段树优化建图，把 O(n²) 条边降到 O(n log n)。
- 看到“恰好一个/至少一个” → 拆成若干二元子句。
- 方案构造：`scc[2*i] < scc[2*i+1]` 取真；也可用 Kosaraju 的拓扑序。
- 判断某个变量是否能取某个值：加一条单元子句再跑一遍，或用传递闭包。

**易错点**

- 取反用 `^1` 时，节点编号必须是 `2x`/`2x+1`；用 `x`/`x+n` 时不能异或 n。
- Tarjan 要跑 `1..2n` 所有点，不能只跑 `1..n`。
- 单元子句 `(x)` 写成 `add_clause(x, true, x, true)`。
- 多测清空图、dfn、low、栈、scc。
- `scc` 编号与“取真/取假”的方向不要记反，写完用小样例验证。

## 2.3 费用流

**算法思路** 在残余网络上找“单位费用最小”的增广路：用 SPFA 求最短路（允许负费用反边），沿最短路增广，直到最短路不存在。反边的费用为 `-c`，流量为 0；每次增广的流量是路径边容量的最小值。若要求最大费用，把费用取负，最后答案取负；若要求“可行流”而不是最大流，增广到目标流量即可。

复杂度：SPFA 最坏 O(nm) 每次增广，实际比赛中通常够用；点数大且费用非负时可用 Dijkstra + 势能。

**核心代码**

```cpp
const int M = 200005;
struct edge { int to, nxt, w, c; } e[M << 1];
int head[N], tot = 1;
ll dis[N];
int inq[N], pre[N], pe[N];

void add(int u, int v, int w, int c) {
    e[++tot] = {v, head[u], w, c};
    head[u] = tot;
    e[++tot] = {u, head[v], 0, -c};
    head[v] = tot;
}

bool spfa(int s, int t, int &flow, ll &cost) {
    memset(dis, 0x3f, sizeof(dis));
    memset(inq, 0, sizeof(inq));
    queue<int> q;
    dis[s] = 0;
    q.push(s);
    inq[s] = 1;
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        inq[u] = 0;
        for (int i = head[u]; i; i = e[i].nxt) {
            int v = e[i].to;
            if (e[i].w && dis[v] > dis[u] + e[i].c) {
                dis[v] = dis[u] + e[i].c;
                pre[v] = u;
                pe[v] = i;
                if (!inq[v]) q.push(v), inq[v] = 1;
            }
        }
    }
    if (dis[t] > LINF) return false;
    int aug = INF;
    for (int v = t; v != s; v = pre[v]) aug = min(aug, e[pe[v]].w);
    for (int v = t; v != s; v = pre[v]) {
        e[pe[v]].w -= aug;
        e[pe[v] ^ 1].w += aug;
    }
    flow += aug;
    cost += 1LL * aug * dis[t];
    return true;
}
```

**经典例题**

- 【模板】P3381 【模板】最小费用最大流。
- 【模板】P4016 负载平衡问题：环形均摊，拆点/供需建图。
- 【进阶】P1251 餐巾计划问题：每天脏/净餐巾拆点，源汇建模。
- 【进阶】P2050 [NOI2012] 美食节：动态加点优化费用流。

**经典套路**

- 看到“每条边有容量和费用，求最小费用” → MCMF。
- 看到“每个点只能用一次” → 拆点，中间连容量 1、费用 0/权值。
- 看到“最大费用” → 费用取负，答案取负；注意负环。
- 看到“上下界” → 无源汇可行流 + 超级源汇，或转成费用流。
- 看到“区间覆盖/选择” → 源点到左端点、右端点到汇点，区间边容量 1 费用 -w。

**易错点**

- 反边费用必须是 `-c`，容量初始 0；`tot` 从 1 开始，`i^1` 才是反边。
- `dis` 用 `long long`；`INF` 不要和 `LINF` 混用。
- SPFA 要清空 `inq`；`pre/pe` 只对更新过的点有效。
- 最大费用取负后可能出现负环，SPFA 仍可处理，但要注意无界情况。
- 多测清空 `head/tot` 和边数组。

## 2.4 矩阵树定理

**算法思路** 无向图生成树个数 = 度数矩阵 − 邻接矩阵（Kirchhoff 矩阵）的任意一个余子式的行列式。有向图分两种：内向树用入度矩阵，外向树用出度矩阵，根节点对应的行列删掉。行列式用高斯消元求，模质数时用逆元；模数非质数时用辗转相除消元。最小生成树计数可以按边权分组，每组内用矩阵树求方案数再相乘；生成树边权和则用变元矩阵树 + 插值。

复杂度：O(n³) 求行列式；MST 计数按权值分组，总 O(n³)。

**核心代码**

```cpp
const int M = 505;
ll a[M][M];

ll det(int n) {
    ll ans = 1;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j++) a[i][j] = (a[i][j] % MOD + MOD) % MOD;
    }
    for (int i = 1; i <= n; i++) {
        int p = i;
        while (p <= n && !a[p][i]) p++;
        if (p > n) return 0;
        if (p != i) { swap(a[p], a[i]); ans = -ans; }
        for (int k = i; k <= n; k++) a[i][k] = (a[i][k] % MOD + MOD) % MOD;
        if (!a[i][i]) return 0;
        ans = ans * a[i][i] % MOD;
        ll inv = qpow(a[i][i], MOD - 2);
        for (int j = i; j <= n; j++) a[i][j] = a[i][j] * inv % MOD;
        for (int j = i + 1; j <= n; j++) {
            ll t = a[j][i];
            if (!t) continue;
            for (int k = i; k <= n; k++) {
                a[j][k] = (a[j][k] - t * a[i][k]) % MOD;
            }
        }
    }
    return (ans % MOD + MOD) % MOD;
}

void add_edge(int u, int v) {
    a[u][u]++;
    a[v][v]++;
    a[u][v]--;
    a[v][u]--;
}
```

**经典例题**

- 【模板】P6178 【模板】Matrix-Tree 定理。
- 【进阶】P4208 [JSOI2008] 最小生成树计数：按边权分组 + 矩阵树。

**经典套路**

- 看到“最小生成树方案数” → Kruskal 分组，每组缩点后矩阵树。
- 看到“有向生成树/根固定” → 入度或出度矩阵，删掉根的行列。
- 看到“生成树权值和/概率” → 变元矩阵树，代入 n 个值插值。

**易错点**

- 自环要去掉；重边要累加，不能只连一条。
- 行列式删掉的是**根所在的行和列**；无向图任意删一行一列。
- 交换两行答案变号，最后要 `(ans % MOD + MOD) % MOD`。
- 消元前把负数归一化，否则逆元会算错。
- MST 计数时，不同权值的边不能混在同一组；每组缩点后点数可能很小。

## 2.5 Kruskal 重构树

**算法思路** 把边按权值从小到大排序，做 Kruskal。每次合并两个连通块时，新建一个节点，点权为当前边权，把两个连通块的根分别作为它的左右儿子。最终得到一棵有 `2n-1` 个节点的树（森林加虚根），叶子是原图的点。关键性质：

- 原图中 `u` 到 `v` 的**最大边权最小**值 = 重构树上 `lca(u,v)` 的点权；
- 重构树中一个节点的子树，恰好是原图在某个阈值下的一個连通块；
- 最小生成树上的路径最大边 = 重构树 LCA 点权。

复杂度：排序 O(m log m)，建树 O(m α)，LCA O(log n)。

**核心代码**

```cpp
struct edge { int u, v, w; } e[N];
vector<int> g[N << 1];
int fa[N << 1], val[N << 1], tot, n, m;

bool cmp(edge a, edge b) { return a.w < b.w; }
int find(int x) { return fa[x] == x ? x : fa[x] = find(fa[x]); }

void build() {
    sort(e + 1, e + m + 1, cmp);
    tot = n;
    for (int i = 1; i <= 2 * n; i++) fa[i] = i;
    for (int i = 1; i <= m; i++) {
        int u = find(e[i].u), v = find(e[i].v);
        if (u == v) continue;
        val[++tot] = e[i].w;
        fa[u] = fa[v] = tot;
        g[tot].push_back(u);
        g[tot].push_back(v);
    }
}

void dfs(int u, int p) {
    dep[u] = dep[p] + 1;
    up[0][u] = p;
    for (int k = 1; k < 20; k++) up[k][u] = up[k - 1][up[k - 1][u]];
    for (int v : g[u]) if (v != p) dfs(v, u);
}
```

**经典例题**

- 【模板】P1967 [NOIP2013] 货车运输：路径最大边最小，重构树 LCA。
- 【进阶】P4197 Peaks：重构树子树第 k 大，主席树/线段树合并。
- 【进阶】P7834 [ONTAK2010] Peaks 加强版：强制在线。
- 【进阶】CF 1706E Qpwoeirut and Vertices：区间连通性，重构树 + 倍增。

**经典套路**

- 看到“最大边最小/最小边最大” → Kruskal 重构树或二分 + 并查集。
- 看到“只走边权 ≤ w 的边能到达哪些点” → 重构树上倍增找到最高祖先。
- 看到“连通块合并历史” → 重构树，子树就是某时刻的连通块。
- 看到“多次询问路径最大边” → 重构树 LCA 点权。
- 重构树叶子按 dfs 序排列后，子树是连续区间，可接主席树。

**易错点**

- 边排序后要判 `u == v`，否则会建出多余节点。
- 原图不连通时是森林，需要建虚根或对每个根分别 dfs。
- 叶子点点权通常设为 0 或 -INF，按题目要求。
- 重构树节点数是 `2n-1`，数组要开两倍。
- 倍增 LCA 的 `up` 要处理根的父亲 0。

## 2.6 建反图

**算法思路** 有些“所有点能否到达 x”的问题，正向做要对每个点跑一遍；把边反向，就变成“从 x 出发能到达哪些点”，一次 BFS/DFS 解决。常见场景：

- 有向图最短路：求所有点到起点的距离，等价于在反图上从起点跑 Dijkstra；
- 可达性：`u` 能到 `v` ↔ 反图中 `v` 能到 `u`；
- 删边/加边离线：把操作倒过来，删边变加边。

复杂度：与正向图相同，O(n + m) 或 O(m log n)。

**核心代码**

```cpp
vector<int> g[N], rg[N];
int vis[N];

void build_rev(int n, vector<pair<int, int>>& edges) {
    for (auto [u, v] : edges) {
        g[u].push_back(v);
        rg[v].push_back(u);
    }
}

void bfs_rev(int s) {
    queue<int> q;
    q.push(s);
    vis[s] = 1;
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        for (int v : rg[u]) {
            if (!vis[v]) {
                vis[v] = 1;
                q.push(v);
            }
        }
    }
}
```

**经典例题**

- 【模板】P1629 邮递员送信：正反两遍 Dijkstra。
- 【模板】P3916 图的遍历：反图 BFS，求每个点能到的最大编号。
- 【进阶】P2296 [NOIP2014] 寻找道路：反图筛掉不能到终点的点。
- 【进阶】CF 505D Mr. Kitayuta's Technology：SCC + 反图/拓扑。

**经典套路**

- 看到“所有点到一个点的距离” → 反图单源最短路。
- 看到“哪些点能到达终点” → 反图从终点 BFS。
- 看到“删边操作” → 时间倒流，删边变加边。
- 看到“有向图可达性” → 反图 + bitset/拓扑。
- 正反两遍 DP：正向求前缀，反向求后缀。

**易错点**

- 反图只反有向边；无向图不需要。
- 反图 BFS 的起点是“终点”，不是原起点。
- 多测清空两张图和 `vis`。
- 时间倒流时，操作顺序和边权要一起反转。

## 2.7 分层图

**算法思路** 当最短路的状态除了“当前点”还有“已经用了几次特权/当前颜色/是否翻转”等维度时，把状态拆成 `(u, k)`，在状态之间连边：

- 不使用特权：`(u,k) → (v,k)`，费用 w；
- 使用一次特权：`(u,k) → (v,k+1)`，费用 0/折扣价；
- 也可以直接开 `dis[u][k]` 跑 Dijkstra，不必显式建两层图。

复杂度：O((nK) log(nK))，空间 O(nK)。

**核心代码**

```cpp
vector<pair<int, int>> g[N];
ll dis[N][25];

struct node {
    ll d;
    int u, k;
    bool operator<(const node& o) const { return d > o.d; }
};

void dij(int s, int K) {
    memset(dis, 0x3f, sizeof(dis));
    priority_queue<node> q;
    dis[s][0] = 0;
    q.push({0, s, 0});
    while (!q.empty()) {
        auto [d, u, k] = q.top();
        q.pop();
        if (d != dis[u][k]) continue;
        for (auto [v, w] : g[u]) {
            if (dis[v][k] > d + w) {
                dis[v][k] = d + w;
                q.push({dis[v][k], v, k});
            }
            if (k < K && dis[v][k + 1] > d) {
                dis[v][k + 1] = d;
                q.push({dis[v][k + 1], v, k + 1});
            }
        }
    }
}
```

**经典例题**

- 【模板】P4568 [JLOI2011] 飞行路线：最多 k 次免费。
- 【模板】P4822 [BJWC2012] 冻结：最多 k 次半价。
- 【进阶】P2939 [USACO09FEB] Revamping Trails G：分层图 + 最短路。
- 【进阶】CF 1473E Minimum Path：边权和减去最大边，状态压缩。

**经典套路**

- 看到“最多 k 次免费/折扣/反转” → 分层图。
- 看到“切换颜色/状态” → 多一层状态，层间边权为切换代价。
- 看到“恰好 k 次” → 限制层数，答案取 `dis[t][k]`。
- 看到“每个点只能用一次” → 拆点 + 层内/层间边。
- 状态数太大时，考虑矩阵快速幂或 DP 优化。

**易错点**

- `dis` 的第二维是 `K+1`，不要只开 K。
- 层间边是单向的，反向边不要漏。
- 优先队列里存 `(d,u,k)`，比较器按 d 小根堆。
- `memset` 0x3f 对 `long long` 是极大值，判断用 `> LINF/2`。
- 多测清空 `dis` 和优先队列。


## 2.8 树的直径

**算法思路** 树的直径是树上最长简单路径。两条经典求法：

- **两次 DFS/BFS**：从任意点出发找到最远点 A，再从 A 出发找到最远点 B，`A-B` 就是一条直径。适用于边权非负；有负权时不能用。
- **树形 DP**：`down[u]` 表示 u 往下的最长链，合并两个儿子的最长链更新答案。适用于任意边权，也能同时求“经过每个点的最长路径”。

关键性质：任意点出发的最远点一定是某条直径的端点；所有直径交于一点或一条边（中点）；直径端点到任意点的最远距离可以用两次 DFS 预处理。

复杂度：O(n)。

**核心代码**

```cpp
vector<pair<int, int>> g[N];
ll dis[N];

void dfs(int u, int p) {
    for (auto [v, w] : g[u]) if (v != p) {
        dis[v] = dis[u] + w;
        dfs(v, u);
    }
}
// 第一次 dfs(1,0)，找 dis 最大的 A；清空 dis 后 dfs(A,0)，找 B。
```

```cpp
ll down[N], ans;
vector<pair<int, int>> g[N];

void dp(int u, int p) {
    down[u] = 0;
    for (auto [v, w] : g[u]) if (v != p) {
        dp(v, u);
        ans = max(ans, down[u] + down[v] + w);
        down[u] = max(down[u], down[v] + w);
    }
}
```

**经典例题**

- 【模板】P3304 [SDOI2013] 直径：求直径长度和所有直径的交。
- 【模板】P4408 [NOI2003] 逃学的小孩：直径端点 + 次长链。
- 【进阶】CF 455C Civilization：动态合并森林，维护每棵树直径。
- 【进阶】P5536 【XR-3】核心城市：直径中点 + 贪心。

**经典套路**

- 看到“树上最远点对” → 两次 DFS 或树形 DP。
- 看到“每个点到最远点距离” → 直径两端点各跑一次，取 max。
- 看到“合并两棵树，使新直径最小” → 连接两棵树的直径中点。
- 看到“所有直径的交” → 找一条直径，向中间缩到所有直径都经过的部分。
- 边权有负时只能用树形 DP。

**易错点**

- 两次 DFS 依赖非负边权；有负权会错。
- `dis` 要开 `long long`，每次 DFS 前清空。
- 多棵树/森林要分别求直径，不能只从一个点开始。
- 树形 DP 的 `ans` 要初始化为 0 或 `-INF`，按边权正负决定。

## 2.9 树的重心

**算法思路** 重心是“删掉它之后，最大连通块最小”的点。求法：以任意点为根，`siz[u]` 为子树大小，删掉 u 后的最大块为 `max(max siz[v], n - siz[u])`，取最小值的点。性质：

- 重心最多两个，且相邻；
- 以重心为根时，每个子树大小不超过 n/2；
- 带权重心是“到所有点距离和最小”的点，可用中位数/树形 DP 求。

复杂度：O(n)。

**核心代码**

```cpp
vector<int> g[N];
int siz[N], mx[N], cen;

void dfs(int u, int p, int n) {
    siz[u] = 1;
    mx[u] = 0;
    for (int v : g[u]) if (v != p) {
        dfs(v, u, n);
        siz[u] += siz[v];
        mx[u] = max(mx[u], siz[v]);
    }
    mx[u] = max(mx[u], n - siz[u]);
    if (mx[u] < mx[cen]) cen = u;
}
// 调用前 mx[0] = INF, cen = 1; dfs(1,0,n);
```

**经典例题**

- 【模板】P1364 医院设置：带权重心/距离和。
- 【模板】P1395 会议：重心到所有点距离和。
- 【进阶】CF 1406C Link Cut Centroids：两个重心的构造。
- 【进阶】P2727 [USACO03FALL] Cow Steeplechase？重心 + 贪心。

**经典套路**

- 看到“删掉一个点使最大连通块最小” → 重心。
- 看到“到所有点距离和最小” → 重心/带权重心。
- 看到“点分治” → 每次找当前连通块的重心。
- 看到“两个重心” → 它们相邻，删掉中间边后两棵子树大小相等。
- 带权重心可以用“中位数”或树形 DP 求。

**易错点**

- `n - siz[u]` 是 u 上方的连通块，不能漏。
- 多棵树要分别找重心；`mx[0]` 要设成 INF。
- 两个重心时，答案可能两个都合法；题目要求编号最小/最大要看清楚。
- 递归深度大时用迭代或开栈。

## 2.10 二分图

**算法思路** 二分图是没有奇环的图，等价于可以黑白染色。判定：DFS/BFS 染色，遇到同色邻居就失败。常见模型：

- **最大匹配**：匈牙利 O(nm) 或 Hopcroft-Karp O(m√n)；
- **最小点覆盖** = 最大匹配（König 定理）；
- **最大独立集** = n − 最大匹配；
- **DAG 最小路径覆盖** = n − 拆点二分图最大匹配；
- **棋盘黑白染色**：相邻格连边，转为二分图。

复杂度：染色 O(n+m)；匈牙利 O(nm)。

**核心代码**

```cpp
vector<int> g[N];
int col[N];

bool dfs_color(int u, int c) {
    col[u] = c;
    for (int v : g[u]) {
        if (col[v] == c) return false;
        if (!col[v] && !dfs_color(v, 3 - c)) return false;
    }
    return true;
}

int match[N], vis[N], tim;

bool dfs(int u) {
    for (int v : g[u]) {
        if (vis[v] == tim) continue;
        vis[v] = tim;
        if (!match[v] || dfs(match[v])) {
            match[v] = u;
            return true;
        }
    }
    return false;
}

int hungarian(int n) {
    int res = 0;
    for (int i = 1; i <= n; i++) {
        ++tim;
        if (dfs(i)) ++res;
    }
    return res;
}
```

**经典例题**

- 【模板】P3386 【模板】二分图最大匹配。
- 【模板】P1640 [SCOI2010] 连续攻击游戏：值域匹配。
- 【进阶】P1155 [NOIP2008] 双栈排序：二分图染色 + 模拟。
- 【进阶】CF 85E Guard Towers：二分 + 二分图判定。

**经典套路**

- 看到“相邻不能同色/分成两组” → 二分图染色。
- 看到“最大匹配/最小点覆盖/最大独立集” → König 定理互转。
- 看到“棋盘、网格、相邻” → 黑白染色。
- 看到“DAG 最小路径覆盖” → 拆点 + 最大匹配。
- 看到“每个物品选一个” → 左侧物品、右侧值域匹配。

**易错点**

- 染色从每个未染色的点开始，图可能不连通。
- 匈牙利 `vis` 用时间戳，避免每次 memset。
- 最大匹配的左右部编号要分清，`match` 存右部匹配的左部点。
- 二分图判定失败时，说明有奇环；不要继续匹配。
- 多测清空 `col/match/vis/tim`。

## 2.11 欧拉回路

**算法思路** 欧拉路径经过每条边恰好一次。判定：

- **无向图**：忽略孤立点后连通；奇度点个数为 0（欧拉回路）或 2（欧拉路径）。
- **有向图**：忽略孤立点后连通；所有点入度=出度（回路），或恰有一个点出度=入度+1（起点）、一个点入度=出度+1（终点）。

Hierholzer 算法：从起点 DFS，能走就走，回溯时把点加入答案；最后逆序输出。要求字典序最小时，把邻接表排序，或按边权从小到大走。

复杂度：O(n + m)。

**核心代码**

```cpp
struct edge { int to, id; };
vector<edge> g[N];
bool used[N << 1];
int deg[N], ans[N], cnt;

void add_edge(int u, int v, int id) {
    g[u].push_back({v, id});
    g[v].push_back({u, id}); // 有向图删掉这一行
    deg[u]++;
    deg[v]++;
}

void dfs(int u) {
    for (auto &e : g[u]) {
        if (used[e.id]) continue;
        used[e.id] = true;
        dfs(e.to);
    }
    ans[++cnt] = u;
}
// 逆序输出 ans[cnt..1]
```

**经典例题**

- 【模板】P7771 【模板】欧拉路径：有向图欧拉路径。
- 【模板】P2731 [USACO3.3] 骑马修栅栏：无向图欧拉路径，字典序最小。
- 【模板】P1341 无序字母对：边是字母对，点是自己。
- 【进阶】CF 1361C Johnny and Megan's Necklace：欧拉回路建模。

**经典套路**

- 看到“每条边恰好走一次” → 欧拉路径/回路。
- 看到“一笔画” → 奇度点个数判定。
- 看到“字典序最小” → 邻接表排序 + Hierholzer。
- 看到“混合图” → 无向边定向 + 网络流/欧拉回路。
- 看到“边双/点双” → 删桥后每个连通块有欧拉回路。

**易错点**

- 先判连通性（忽略孤立点），再判度数。
- 无向图每条边要标记两个方向，`id` 相同；有向图 `id` 唯一。
- 欧拉路径的起点：无向图是奇度点，有向图是出度比入度大 1 的点；回路任意非孤立点。
- 递归深度可能到 m，必要时改迭代/开栈。
- 多测清空 `g/used/deg/ans/cnt`。

## 2.12 虚树

**算法思路** 多次询问，每次只涉及少量关键点，但关键点之间的路径很长。虚树只保留关键点和它们的 LCA，把原树压缩成一棵大小 O(k) 的树。建法：

1. 按 dfs 序排序关键点；
2. 相邻关键点的 LCA 也加入，去重后再按 dfs 序排序；
3. 用单调栈维护右链：若栈顶不是当前点的祖先，弹栈；否则连边。

虚树上每条边的权是原树上两点的距离，DP 时按这条边权计算。总复杂度 O(k log k)（排序 + LCA）。

**核心代码**

```cpp
vector<int> g[N], vt[N];
int tin[N], tout[N], tim;

void dfs(int u, int p) {
    tin[u] = ++tim;
    dep[u] = dep[p] + 1;
    up[0][u] = p;
    for (int k = 1; k < 20; k++) up[k][u] = up[k - 1][up[k - 1][u]];
    for (int v : g[u]) if (v != p) dfs(v, u);
    tout[u] = tim;
}

bool is_anc(int u, int v) { return tin[u] <= tin[v] && tout[v] <= tout[u]; }

void build_vt(vector<int>& a) {
    sort(a.begin(), a.end(), [](int x, int y) { return tin[x] < tin[y]; });
    int k = a.size();
    for (int i = 0; i + 1 < k; i++) a.push_back(lca(a[i], a[i + 1]));
    sort(a.begin(), a.end(), [](int x, int y) { return tin[x] < tin[y]; });
    a.erase(unique(a.begin(), a.end()), a.end());
    vector<int> st;
    for (int u : a) {
        while (!st.empty() && !is_anc(st.back(), u)) st.pop_back();
        if (!st.empty()) vt[st.back()].push_back(u);
        st.push_back(u);
    }
    // vt[st[0]] 是虚树根
}
```

**经典例题**

- 【模板】P2495 [SDOI2011] 消耗战：虚树 + 最小割/树形 DP。
- 【进阶】P4103 [HEOI2014] 大工程：虚树上统计距离和/最值。
- 【进阶】CF 613D Kingdom and its Cities：虚树 + 贪心。
- 【进阶】P3233 [HNOI2014] 世界树：虚树 + 倍增/分类讨论。

**经典套路**

- 看到“多次询问，每次给 k 个关键点” → 虚树。
- 看到“关键点之间的路径/最近公共祖先” → 虚树 + LCA。
- 看到“删除最少的点使关键点不连通” → 虚树 + 贪心/DP。
- 虚树上边权用原树距离，不要直接用 1。
- 每次询问后只清空虚树上的点，不要清空整棵树。

**易错点**

- 关键点要先去重，再加入相邻 LCA；加完 LCA 后还要再排序去重。
- `tout` 是子树最大 dfs 序，`is_anc(u,v)` 用 `tin[u] <= tin[v] && tout[v] <= tout[u]`。
- 虚树根是 `st[0]`；如果需要超级根，按题目加。
- 清空 `vt` 时只清关键点和 LCA，避免 O(n) 清空。
- LCA 的 `up` 要预处理到 `log n`。

## 2.13 换根 DP

**算法思路** 先以 1 为根做一次子树 DP，得到 `down[u]`；再换根，利用父节点答案推出子节点答案。经典例子“求每个点到其他点的距离和”：

- 第一次 DFS：`siz[u]`、`f[u] = Σ(f[v] + siz[v])`；
- 换根：`f[v] = f[u] + n - 2*siz[v]`；
- 第二次 DFS 把 `f` 推到所有点。

更一般地，换根时要把“父节点对子节点的贡献”从总答案中扣掉，再加上“子节点对父节点的贡献”；常用前后缀 max/和来合并兄弟贡献。

复杂度：O(n)。

**核心代码**

```cpp
vector<int> g[N];
ll siz[N], f[N], ans;
int n;

void dfs1(int u, int p) {
    siz[u] = 1;
    for (int v : g[u]) if (v != p) {
        dfs1(v, u);
        siz[u] += siz[v];
        f[u] += f[v] + siz[v];
    }
}

void dfs2(int u, int p) {
    ans = max(ans, f[u]);
    for (int v : g[u]) if (v != p) {
        f[v] = f[u] + n - 2 * siz[v];
        dfs2(v, u);
    }
}
```

**经典例题**

- 【模板】P3478 [POI2008] STA-Station：换根求最大深度和。
- 【模板】P2986 [USACO10MAR] Great Cow Gathering G：带权距离和。
- 【进阶】P3047 [USACO12FEB] Nearby Cows G：换根 + 距离 ≤ k 的权值和。
- 【进阶】CF 219D Choosing Capital for Treeland：换根求最少反向边。

**经典套路**

- 看到“每个点作为根时的答案” → 换根 DP。
- 看到“所有点到某点的距离和” → 两次 DFS + `n-2*siz`。
- 看到“每个点向下/向上的最长链” → 换根 + 前后缀 max。
- 看到“选一个根使某值最大/最小” → 先求一个根，再换根比较。
- 兄弟贡献用前缀/后缀合并，避免 O(deg²)。

**易错点**

- 换根公式里的 `n` 是整棵树大小，不是子树大小。
- `siz` 和答案用 `long long`；`n - 2*siz[v]` 可能为负。
- 叶子节点没有儿子，换根时不要越界。
- 多次 DFS 要清空 `f/down/up`；多测尤其注意。
- 带权距离要把边权乘进 `siz` 的贡献。

## 2.14 拓展域 DSU

**算法思路** 当关系不是“相等”而是“同类/异类”时，可以把每个点拆成两个域：`x` 表示“与 x 同类”，`x+n` 表示“与 x 异类”。合并规则：

- `x` 与 `y` 同类：`uni(x,y)`、`uni(x+n,y+n)`；
- `x` 与 `y` 异类：`uni(x,y+n)`、`uni(x+n,y)`；
- 矛盾：`find(x) == find(x+n)`。

这本质上是 2-SAT 的并查集特例；如果关系是“模 3 意义下的三类”，用带权 DSU 更直接。

复杂度：O(α(n)) 每次操作。

**核心代码**

```cpp
int fa[N << 1];

int find(int x) { return fa[x] == x ? x : fa[x] = find(fa[x]); }
void uni(int x, int y) { fa[find(x)] = find(y); }
bool same(int x, int y) { return find(x) == find(y); }

void init(int n) {
    for (int i = 1; i <= 2 * n; i++) fa[i] = i;
}

// 同类：uni(x,y), uni(x+n,y+n)
// 异类：uni(x,y+n), uni(x+n,y)
// 矛盾：find(x) == find(x+n)
```

**经典例题**

- 【模板】P2024 [NOI2001] 食物链：三类关系，带权 DSU/拓展域。
- 【模板】P1892 [BOI2003] 团伙：朋友的朋友是朋友，敌人的敌人是朋友。
- 【进阶】P5937 [CEOI1999] Parity Game：奇偶性，带权/拓展域。
- 【进阶】P1525 [NOIP2010] 关押罪犯：二分 + 二分图，或拓展域 DSU。

**经典套路**

- 看到“朋友/敌人/同类/异类” → 拓展域 DSU。
- 看到“敌人的敌人是朋友” → 异类合并。
- 看到“奇偶性/模 k 关系” → 带权 DSU。
- 看到“矛盾最早出现” → 按顺序合并，第一次矛盾即答案。
- 看到“二分答案 + 可行性” → 二分图判定或拓展域 DSU。

**易错点**

- 初始化到 `2n`，不是 n。
- `x` 和 `x+n` 的编号不要混；`find(x)==find(x+n)` 才是矛盾。
- 带权 DSU 的路径压缩要同时更新到根的距离/模值。
- 多测清空 `fa[1..2n]`。
- 三类关系（食物链）用拓展域要开 3n，不是 2n。


# 第 3 部分 数学、计数与几何

数学题的共同点是：先写出暴力式子，再用容斥、卷积、矩阵或组合恒等式降复杂度。本部分只保留比赛中最常用的结论和代码骨架，证明从略。

## 3.1 容斥系数

**算法思路** 容斥的本质是“先算至少，再减掉重复”。最常用的两种形式：

- **并集容斥**：`|A₁ ∪ ... ∪ Aₙ| = Σ(-1)^{|S|+1} |∩_{i∈S} A_i|`；
- **补集/至少**：把“恰好满足 k 个”转成“至少满足 k 个”的二项式反演；
- **子集容斥**：枚举子集 S，系数 `(-1)^{|S|}`，常用于“每个位置都不能选某些值”的计数。

写容斥时先明确“全集”和“坏事件”，再决定系数是 `(-1)^{|S|}` 还是 `(-1)^{|S|+1}`；这两者只差一个整体符号。

复杂度：O(2^m) 枚举子集，或 O(n) 二项式反演。

**核心代码**

```cpp
ll inclusion_exclusion(int m) {
    ll ans = 0;
    for (int S = 1; S < (1 << m); S++) {
        int pc = __builtin_popcount(S);
        ll ways = 1; // 替换成“交集”的大小/方案数
        ans += (pc & 1) ? ways : -ways;
    }
    return ans;
}
```

**经典例题**

- 【模板】P1450 [HAOI2008] 硬币购物：完全背包 + 容斥减去超限。
- 【进阶】P3172 [CQOI2015] 选数：gcd 恰好为 k，莫比乌斯/容斥。
- 【进阶】P4859 已经没有什么好害怕的了：二项式反演。
- 【进阶】CF 451E Devu and Flowers：多重集组合 + 容斥。

**经典套路**

- 看到“至少/恰好” → 二项式反演或容斥。
- 看到“每个位置有若干禁用值” → 子集容斥。
- 看到“并集大小” → `(-1)^{|S|+1}`。
- 看到“补集更好算” → 算总方案减不合法。
- 容斥系数不确定时，先用小数据暴力对拍。

**易错点**

- 空集是否计入：并集容斥从 `S=1` 开始；补集容斥可能包含 `S=0`。
- 系数符号写反，整体答案会反号；用 n=1 的特例检查。
- 模运算下减法要 `(x % MOD + MOD) % MOD`。
- 子集枚举 `S = (S-1) & mask` 不要写成 `S--`。
- 容斥的交集大小要能快速计算，否则先预处理。

## 3.2 范德蒙德卷积

**算法思路** 范德蒙德卷积：

$$
\sum_{i=0}^{k} \binom{n}{i}\binom{m}{k-i}=\binom{n+m}{k}
$$

组合意义是“从 n 个和 m 个物品中一共选 k 个”。它的常见用途是把“两类物品分别选”的双重求和合并成一个组合数；当式子里出现 `C(i, j) * C(n-i, k-j)` 时，优先想它。下标从 0 开始，越界项按 0 处理。

复杂度：预处理阶乘 O(n)，单次组合数 O(1)；直接求和 O(k)。

**核心代码**

```cpp
ll fac[N], ifac[N];

ll C(int n, int m) {
    if (m < 0 || m > n || n < 0) return 0;
    return fac[n] * ifac[m] % MOD * ifac[n - m] % MOD;
}

void init(int n) {
    fac[0] = 1;
    for (int i = 1; i <= n; i++) fac[i] = fac[i - 1] * i % MOD;
    ifac[n] = qpow(fac[n], MOD - 2);
    for (int i = n; i >= 1; i--) ifac[i - 1] = ifac[i] * i % MOD;
}

ll vandermonde(int n, int m, int k) {
    ll s = 0;
    for (int i = 0; i <= k; i++) s = (s + C(n, i) * C(m, k - i)) % MOD;
    return s;
}
```

**经典例题**

- 【模板】CF 785D Anton and School - 2：左右括号计数 + 范德蒙德。
- 【进阶】CCPC 网络赛 M 中位数为 X：枚举中位数位置后合并左右方案。
- 【进阶】P2822 [NOIP2016] 组合数问题：组合数递推 + 二维前缀和。
- 【进阶】P3414 SAC#1 - 组合数：二项式定理求和。

**经典套路**

- 看到 `Σ C(i,j) C(n-i,k-j)` → 范德蒙德。
- 看到“枚举分界点，左右各选一些” → 合并成 `C(n,k)`。
- 看到 `(1+x)^n (1+x)^m = (1+x)^{n+m}` → 生成函数视角。
- 上指标求和用裂项，下指标求和用 `2^k`。
- 组合数取模前先确认 `n < MOD`；否则用 Lucas。

**易错点**

- 下标从 0 开始；`C(n,0)=1`，`C(n,n)=1`。
- `ifac` 递推方向不要写反：`ifac[i-1] = ifac[i] * i`。
- `n` 可能大于 `MOD`，普通阶乘逆元失效，要用 Lucas。
- 双重求和换序时注意边界，越界项用 `C=0` 兜底。
- 取模减法要归一化。

## 3.3 min-max 容斥

**算法思路** 经典的 min-max 容斥：

$$
\max(S)=\sum_{\varnothing\ne T\subseteq S}(-1)^{|T|+1}\min(T)
$$

把 max 换成 min 也成立。期望形式：

$$
E[\max(S)]=\sum_{\varnothing\ne T\subseteq S}(-1)^{|T|+1}E[\min(T)]
$$

它适合“所有元素都出现/都满足”的期望问题：`E[min(T)]` 往往比 `E[max(S)]` 好算（例如“T 中至少一个出现”）。第 k 大的 min-max 容斥系数是 `(-1)^{|T|-k} C(|T|-1,k-1)`。

复杂度：O(2^m) 枚举子集；m 较大时用 DP 合并系数。

**核心代码**

```cpp
const int MAXS = 1 << 20;
ll f[MAXS]; // f[T] = E[min(T)]
int S;

ll minmax_exclusion() {
    ll ans = 0;
    for (int T = S; T; T = (T - 1) & S) {
        int pc = __builtin_popcount(T);
        ans += (pc & 1 ? 1 : -1) * f[T];
    }
    return ans;
}
```

**经典例题**

- 【模板】P3175 [HAOI2015] 按位或：期望时间，min-max + 按位。
- 【进阶】P4707 重返现世：第 k 大 min-max 容斥。
- 【进阶】CF 175F? 期望收集：所有元素至少出现一次。
- 【进阶】P4491 [HAOI2018] 染色：恰好出现次数，二项式反演。

**经典套路**

- 看到“所有元素都出现”的期望 → min-max 容斥。
- 看到“至少一个出现”的期望 → `E[min]` 直接算。
- 看到“第 k 大/小” → 带组合系数的 min-max。
- 按位拆开，分别求每一位的期望再相加。
- 子集太大时，把系数压进 DP 状态。

**易错点**

- 空集不参与；`T` 从 `S` 开始枚举，非空。
- 系数符号 `(-1)^{|T|+1}`，不要漏 1。
- 期望的线性性可以直接拆，但 min/max 不能随意拆。
- 概率为 0 时 `E[min]` 可能无穷，要特判无解。
- 第 k 大的系数与普通 min-max 不同。

## 3.4 转化括号序列 + 卡特兰数

**算法思路** 把左括号看成 +1、右括号看成 -1，括号序列合法当且仅当：

- 任意前缀和 ≥ 0；
- 总和 = 0。

“任意前缀非负”的路径计数可以用**反射原理**：从 `(0,0)` 到 `(n,n)` 不穿过 `y=x` 的路径数是卡特兰数 `C_n = C(2n,n)/(n+1)`。常见模型：n 个元素的出栈序列、n 对括号、二叉树形态、不越过对角线的网格路径。括号树则把匹配关系建成树，处理区间 DP/贡献。

复杂度：预处理卡特兰 O(n)，单次 O(1)。

**核心代码**

```cpp
ll cat[N];

void init_catalan(int n) {
    cat[0] = 1;
    for (int i = 0; i < n; i++) {
        cat[i + 1] = cat[i] * (4 * i + 2) % MOD * qpow(i + 2, MOD - 2) % MOD;
    }
}
```

```cpp
bool check(const string& s) {
    int bal = 0;
    for (char c : s) {
        if (c == '(') bal++;
        else bal--;
        if (bal < 0) return false;
    }
    return bal == 0;
}
```

**经典例题**

- 【模板】P1044 栈：出栈序列数 = 卡特兰数。
- 【模板】P1641 [SCOI2010] 生成字符串：不越过对角线的路径。
- 【进阶】P2532 [AHOI2012] 树屋阶梯：卡特兰数的几何模型。
- 【进阶】CF 5C Longest Regular Bracket Sequence：最长合法括号子串 + 计数。

**经典套路**

- 看到“n 对括号的方案数” → 卡特兰。
- 看到“任意前缀和非负” → 反射原理/卡特兰。
- 看到“括号匹配/括号树” → 栈 + 树形 DP。
- 看到“合法括号子串” → 前缀和 + 最近一次非法位置。
- 看到“区间加括号” → 括号树 + 贡献。

**易错点**

- 卡特兰数下标从 `C_0=1` 开始；`C_1=1, C_2=2, C_3=5`。
- 模数下除法用逆元；`n+1` 可能等于 MOD，需要特判。
- 反射原理的边界是“不穿过”，不是“不接触”。
- 括号序列长度必须为偶数；奇数直接无解。
- 多测预处理一次即可，不要重复 O(n)。

## 3.5 数位 DP

**算法思路** 数位 DP 按十进制位从高到低枚举，状态通常包括：

- `pos`：当前位；
- `limit`：是否贴着上界；
- `lead`：是否有前导零；
- 题目相关的状态（上一位、出现次数、模数、是否满足性质）。

答案用前缀差分：`[0,r] - [0,l-1]`。记忆化时只记忆 `limit=false` 的状态，避免把“贴上限”的答案混进去。

复杂度：状态数 × 10 × 位数。

**核心代码**

```cpp
int a[20], len;
ll f[20][2][2][7];

ll dfs(int pos, bool lim, bool lead, int state) {
    if (pos == len) return 1;
    ll &res = f[pos][lim][lead][state];
    if (res != -1) return res;
    res = 0;
    int up = lim ? a[pos] : 9;
    for (int d = 0; d <= up; d++) {
        if (lead && d == 0) res += dfs(pos + 1, lim && d == up, true, state);
        else res += dfs(pos + 1, lim && d == up, false, (state * 10 + d) % 7);
    }
    return res;
}

ll solve(ll x) {
    len = 0;
    while (x) a[len++] = x % 10, x /= 10;
    reverse(a, a + len);
    memset(f, -1, sizeof(f));
    return dfs(0, true, true, 0);
}
```

**经典例题**

- 【模板】P2602 [ZJOI2010] 数字计数：统计每个数字出现次数。
- 【模板】P2657 [SCOI2009] windy 数：相邻数字差至少 2。
- 【进阶】P4124 [CQOI2016] 手机号码：连续三位、4/8 限制。
- 【进阶】CF 628D Magic Numbers：模数 + 数位限制。

**经典套路**

- 看到“区间内满足数位性质的数个数” → 数位 DP。
- 看到“统计数字出现次数” → 按位贡献/数位 DP。
- 看到“不能有前导零” → `lead` 状态。
- 看到“上界限制” → `limit` 状态，记忆化只存非 limit。
- 看到“模数/整除” → 把余数放进状态。

**易错点**

- `solve(0)` 的边界；`len=0` 时返回 1 还是 0 要按题意。
- 前导零状态下的 0 不能算作数字出现。
- `limit && d == up` 才是新的 limit。
- 记忆化数组只清一次；多测用 `memset(f,-1)`。
- 上界 `l-1` 当 `l=0` 时要特判。

## 3.6 矩阵快速幂

**算法思路** 矩阵乘法满足结合律，因此可以用快速幂把“递推 k 次”压到 O(n³ log k)。常见模型：

- 线性递推：Fibonacci、`f[i]=a*f[i-1]+b*f[i-2]`；
- 图上游走：邻接矩阵的 k 次方，`(A^k)[u][v]` 表示 u 到 v 长度 k 的路径数；
- 带常数项/前缀和：矩阵加一维；
- 广义矩阵：把 `+` 换成 `max/min`，把 `*` 换成 `+`，用于最短路/DP。

复杂度：O(n³ log k)，n 是矩阵大小。

**核心代码**

```cpp
struct Matrix {
    int n;
    ll a[105][105];
    Matrix(int n = 0) : n(n) { memset(a, 0, sizeof(a)); }

    Matrix operator*(const Matrix& b) const {
        Matrix c(n);
        for (int i = 1; i <= n; i++)
            for (int k = 1; k <= n; k++) if (a[i][k])
                for (int j = 1; j <= n; j++)
                    c.a[i][j] = (c.a[i][j] + a[i][k] * b.a[k][j]) % MOD;
        return c;
    }
};

Matrix mpow(Matrix a, ll b) {
    Matrix r(a.n);
    for (int i = 1; i <= r.n; i++) r.a[i][i] = 1;
    for (; b; b >>= 1, a = a * a) if (b & 1) r = r * a;
    return r;
}
```

**经典例题**

- 【模板】P3390 【模板】矩阵快速幂。
- 【模板】P1962 斐波那契数列：2×2 转移矩阵。
- 【模板】P1939 【模板】矩阵加速（数列）：三项递推。
- 【进阶】P3758 [TJOI2017] 可乐：邻接矩阵 + 停留边，求长度 ≤ k 的路径数。

**经典套路**

- 看到“递推式固定、次数很大” → 矩阵快速幂。
- 看到“图上走 k 步的方案数” → 邻接矩阵的 k 次方。
- 看到“带常数项” → 矩阵加一维常数 1。
- 看到“前缀和” → 矩阵加一维累加。
- 看到“max/min 转移” → 广义矩阵（max-plus）。

**易错点**

- 矩阵乘法顺序不能交换；`r = r * a` 与 `a * r` 不同。
- 单位矩阵是对角线 1，其余 0。
- 初始向量要乘在正确的一侧。
- `n` 较大时 O(n³) 会超时；用稀疏矩阵/特征多项式优化。
- 取模乘法用 `long long`，避免溢出。

## 3.7 矩阵快速幂优化 DP 转移

**算法思路** 当 DP 转移是线性的、但阶段很多时，把转移写成矩阵；当转移还会被单点修改时，用线段树维护矩阵乘积。两类常见模型：

- **线性递推**：`f[i] = Σ a[j] f[i-j]`，构造转移矩阵后 `mpow`；
- **动态 DP**：把树形 DP 的转移写成矩阵，重链剖分后用线段树维护矩阵乘积，支持单点修改。

广义矩阵（max-plus）把乘法换成加法、加法换成 max，可用于“最长路/最大权 DP”的快速幂。

复杂度：矩阵快速幂 O(n³ log k)；线段树维护矩阵 O(n log n * m³)，m 是矩阵大小。

**核心代码**

```cpp
struct Matrix {
    int n;
    ll a[55][55];
    Matrix(int n = 0) : n(n) {
        for (int i = 1; i <= n; i++)
            for (int j = 1; j <= n; j++) a[i][j] = -LINF;
    }
    Matrix operator*(const Matrix& b) const {
        Matrix c(n);
        for (int i = 1; i <= n; i++)
            for (int k = 1; k <= n; k++) if (a[i][k] > -LINF)
                for (int j = 1; j <= n; j++)
                    c.a[i][j] = max(c.a[i][j], a[i][k] + b.a[k][j]);
        return c;
    }
};
```

```cpp
struct Mat {
    ll a[2][2];
};

Mat merge(Mat x, Mat y) {
    Mat z{};
    for (int i = 0; i < 2; i++)
        for (int j = 0; j < 2; j++) z.a[i][j] = -LINF;
    for (int i = 0; i < 2; i++)
        for (int k = 0; k < 2; k++) if (x.a[i][k] > -LINF)
            for (int j = 0; j < 2; j++)
                z.a[i][j] = max(z.a[i][j], x.a[i][k] + y.a[k][j]);
    return z;
}

Mat seg[N << 2];
void pushup(int p) { seg[p] = merge(seg[p << 1], seg[p << 1 | 1]); }
```

**经典例题**

- 【模板】CF 750E New Year and Old Subsequence：线段树维护“包含 2017 不含 2016”的矩阵。
- 【进阶】P4719 【模板】动态 DP：树链剖分 + 矩阵。
- 【进阶】P2886 [USACO07NOV] Cow Relays G：广义矩阵快速幂。
- 【进阶】P4159 [SCOI2009] 迷路：边权拆点 + 矩阵快速幂。

**经典套路**

- 看到“DP 转移固定、阶段多” → 矩阵快速幂。
- 看到“单点修改 + 查询整体 DP” → 线段树维护矩阵乘积。
- 看到“最长路/最大权” → max-plus 矩阵。
- 看到“边权 1..9” → 拆成 9 个点，转 0/1 矩阵。
- 动态 DP 的矩阵要按“轻儿子贡献固定、重儿子可变”构造。

**易错点**

- max-plus 矩阵的单位元是“对角线 0，其余 -INF”，不是单位矩阵。
- 线段树合并顺序是左乘右，不能反。
- 矩阵大小要按状态数开，不要盲目 55×55。
- 动态 DP 的初始向量/边界要单独处理。
- 取模矩阵与 max-plus 矩阵不要混用。

## 3.8 SG 函数

**算法思路** 公平组合游戏中，每个局面 x 的 SG 值：

$$
SG(x)=\operatorname{mex}\{SG(y)\mid x\to y\}
$$

多堆游戏的和的 SG 值是各堆 SG 的异或；异或和非 0 先手必胜。常见模型：Nim、取石子、拆分游戏、阶梯博弈。SG 值通常可以打表找规律；如果局面可以拆成独立的子游戏，SG 就是子游戏 SG 的异或。

复杂度：O(状态数 × 转移数)。

**核心代码**

```cpp
vector<int> nxt[N];
int sg[N];

int get_sg(int x) {
    if (sg[x] != -1) return sg[x];
    bool vis[128] = {};
    for (int y : nxt[x]) vis[get_sg(y)] = true;
    int g = 0;
    while (vis[g]) g++;
    return sg[x] = g;
}
// 多堆：异或和 != 0 先手必胜
```

**经典例题**

- 【模板】P2197 【模板】Nim 游戏：异或和判定。
- 【模板】P2575 高手过招：阶梯博弈/SG。
- 【进阶】P3235 [HNOI2014] 江南乐：SG 打表 + 整除分块。
- 【进阶】CF 138D World of Darkraft: Battle for Azathoth：SG + 二维拆分。

**经典套路**

- 看到“公平组合游戏、两人轮流” → SG。
- 看到“多堆独立游戏” → 异或和。
- 看到“每次可以取/放/拆分” → 打表找 SG 规律。
- 看到“阶梯” → 只关心奇数层/偶数层的异或。
- 看到“环/图上的游戏” → 拓扑/记忆化搜索。

**易错点**

- `sg` 初始化为 -1；0 是合法 SG，不能用 0 表示未访问。
- 终止局面的 SG 是 0。
- 多堆是异或，不是求和。
- 打表时范围要足够大，避免规律没出现。
- 有环的游戏不能直接 DFS，需要特殊处理/题目保证无环。

## 3.9 凸包

**算法思路** 二维凸包是包含所有点的最小凸多边形。Andrew 算法：

1. 按 x 再按 y 排序，去重；
2. 从左到右维护下凸壳：若最后三个点叉积 ≤ 0，弹出中间点；
3. 从右到左维护上凸壳；
4. 合起来去掉重复端点。

叉积 `(b-a)×(c-a) > 0` 表示左转。若要求保留共线点，把 `<= 0` 改成 `< 0`。旋转卡壳可以在凸包上求直径、最小矩形覆盖、最大三角形等。

复杂度：排序 O(n log n)，求凸包 O(n)，旋转卡壳 O(n)。

**核心代码**

```cpp
struct Point {
    ll x, y;
    Point operator-(const Point& b) const { return {x - b.x, y - b.y}; }
    ll operator*(const Point& b) const { return x * b.y - y * b.x; }
    bool operator<(const Point& b) const { return x == b.x ? y < b.y : x < b.x; }
};

ll cross(Point a, Point b, Point c) { return (b - a) * (c - a); }

vector<Point> convex_hull(vector<Point> p) {
    sort(p.begin(), p.end());
    p.erase(unique(p.begin(), p.end(), [](Point a, Point b) {
        return a.x == b.x && a.y == b.y;
    }), p.end());
    int n = p.size();
    if (n <= 1) return p;
    vector<Point> h(2 * n);
    int k = 0;
    for (int i = 0; i < n; i++) {
        while (k >= 2 && cross(h[k - 2], h[k - 1], p[i]) <= 0) k--;
        h[k++] = p[i];
    }
    for (int i = n - 2, t = k + 1; i >= 0; i--) {
        while (k >= t && cross(h[k - 2], h[k - 1], p[i]) <= 0) k--;
        h[k++] = p[i];
    }
    h.resize(k - 1);
    return h;
}
```

**经典例题**

- 【模板】P2742 【模板】二维凸包：周长。
- 【模板】P1452 [USACO03FALL] Beauty Contest G：凸包直径，旋转卡壳。
- 【进阶】P3187 [HNOI2007] 最小矩形覆盖：旋转卡壳。
- 【进阶】CF 70D Professor's task：动态凸包。

**经典套路**

- 看到“包含所有点的最小凸多边形/周长” → 凸包。
- 看到“凸包直径/最远点对” → 旋转卡壳。
- 看到“最小矩形/最大三角形” → 凸包 + 旋转卡壳/三分。
- 看到“斜率优化” → 维护下凸壳/上凸壳。
- 看到“动态加点凸包” → 有序 set 维护上下凸壳。

**易错点**

- 叉积用 `long long`；坐标乘积可能超 int。
- 共线点：`<= 0` 会去掉共线点，`< 0` 保留；按题目要求。
- 重复点先去重，否则凸包会出现零长度边。
- 浮点几何要加 eps；本模板用整数叉积，避免精度问题。
- 旋转卡壳的指针移动条件是“面积不增”，注意平行动边。


# 第 4 部分 字符串与哈希

字符串题的两条主线：**前缀函数/ border** 处理周期与匹配，**随机哈希** 把“集合/序列是否相同”压成一个数。哈希不是绝对正确，重要题目用双哈希或直接上确定算法。

## 4.1 KMP 与 border

**算法思路** `nxt[i]` 表示 `s[0..i]` 的最长真 border 长度（既是前缀又是后缀）。求法：失配时沿 `nxt[j-1]` 跳，直到能匹配或 j=0。KMP 匹配时同理，匹配成功后 `j = nxt[j-1]` 继续找下一次出现。

border 的关键性质：

- 最小周期 = `n - nxt[n-1]`；若 `n % (n - nxt[n-1]) == 0`，则是完整周期；
- 所有 border 长度构成一条链：`n, nxt[n-1], nxt[nxt[n-1]-1], ...`；
- 把每个位置向 `nxt[i-1]` 连边，得到**失配树**（border tree），祖先关系对应 border。

复杂度：O(n + m)。

**核心代码**

```cpp
int nxt[N];

void get_next(const string& s) {
    int n = s.size();
    nxt[0] = 0;
    for (int i = 1, j = 0; i < n; i++) {
        while (j && s[i] != s[j]) j = nxt[j - 1];
        if (s[i] == s[j]) j++;
        nxt[i] = j;
    }
}

vector<int> match(const string& s, const string& t) {
    vector<int> pos;
    get_next(t);
    for (int i = 0, j = 0; i < (int)s.size(); i++) {
        while (j && s[i] != t[j]) j = nxt[j - 1];
        if (s[i] == t[j]) j++;
        if (j == (int)t.size()) {
            pos.push_back(i - j + 1);
            j = nxt[j - 1];
        }
    }
    return pos;
}
```

**经典例题**

- 【模板】P3375 【模板】KMP：输出所有匹配位置和前缀函数。
- 【进阶】P2375 [NOI2014] 动物园：统计不超过一半的 border 链。
- 【进阶】P3426 [POI2005] SZA-Template：border 树 + 覆盖。
- 【进阶】CF 432D Prefixes and Suffixes：所有 border 及其出现次数。
- 【进阶】P5829 【模板】失配树：border 树 LCA。

**经典套路**

- 看到“前缀=后缀” → border/前缀函数。
- 看到“周期/循环节” → `n - nxt[n-1]`。
- 看到“所有 border 的出现次数” → 失配树上子树和。
- 看到“最长公共前后缀” → 扩展 KMP 或哈希 + 二分。
- 看到“字符串匹配后继续找” → 匹配成功后 `j=nxt[j-1]`。

**易错点**

- `nxt` 是 0-index；`nxt[0]=0`，空串要特判。
- 求 `nxt` 时 `j` 是长度，不是下标；比较 `s[i]` 与 `s[j]`。
- 匹配成功后要跳 `nxt[j-1]`，否则会漏掉重叠匹配。
- 周期判断要整除，不能只看 `n-nxt[n-1]`。
- 多测清空 `nxt`。

## 4.2 随机化与 xor 哈希

**算法思路** 给每个值分配一个随机 64 位权值，序列的哈希定义为权值的异或和。异或哈希只关心“每个值出现次数的奇偶性”，适合：

- 判断两个序列/集合是否相同（重排后相同）；
- 判断区间内是否每个数出现偶数次；
- 树哈希：子树权值异或，判断树同构；
- 随机采样：绝对众数、随机化构造。

随机化的正确性依赖碰撞概率；重要题目用双哈希/128 位，或改用确定算法。随机源用 `mt19937_64`，不要用 `rand()`。

复杂度：预处理 O(n)，查询 O(1)。

**核心代码**

```cpp
mt19937_64 rng(chrono::steady_clock::now().time_since_epoch().count());
ull val[N], h[N];
int a[N];

void init_hash(int n) {
    for (int i = 1; i <= n; i++) val[i] = rng();
    for (int i = 1; i <= n; i++) h[i] = h[i - 1] ^ val[a[i]];
}

ull range_hash(int l, int r) { return h[r] ^ h[l - 1]; }
```

**经典例题**

- 【模板】CF 1175F The Number of Subpermutations：判断区间是否为排列。
- 【进阶】CF 1418G Three Occurrences：每个数出现次数为 3 的倍数。
- 【进阶】P5043 【模板】树同构：树哈希。
- 【进阶】P4062 [Code+#1] Yazid 的新生舞会：随机化/分治。

**经典套路**

- 看到“两个序列重排后是否相同” → 异或哈希/和哈希。
- 看到“每个数出现偶数次” → 异或哈希。
- 看到“区间是否为排列” → 异或哈希 + `max-min+1=len`。
- 看到“树同构” → 子树哈希排序/异或。
- 看到“绝对众数” → 随机采样 30 次 + 二分计数。

**易错点**

- 异或哈希对“出现次数模 2”敏感，不能判断具体次数。
- 随机权值要足够随机；固定种子可能被构造数据卡。
- 双哈希/128 位更稳；单哈希 64 位碰撞概率约 2^-64。
- 树哈希要固定根；无根树取重心/换根哈希。
- 使用 `val[a[i]]` 前先把 `a[i]` 离散化到 `1..N`，否则直接越界。
- 多测重新生成权值或清空哈希数组。

# 第 5 部分 思维与技巧

这一部分不是具体算法，而是“看到题面后如何选工具”。核心是复杂度平衡：根号分治、双指针、反悔贪心，都是把暴力优化到可接受的范围。

## 5.1 根号思维

**算法思路** 根号思维有三类常见形式：

1. **分块**：把序列分成 √n 块，整块打标记，零散块暴力；适合区间加、区间和、区间众数。
2. **根号分治**：按“出现次数/权值大小”分成大、小两类，小类暴力，大类预处理；例如哈希冲突按模数分块。
3. **阈值重构**：操作次数少时暴力，次数多时重建；例如弹飞绵羊的块内跳转。

块大小通常取 `B = sqrt(n)` 或 `B = n / sqrt(q)`；块太大零散暴力慢，块太小整块多。

复杂度：O((n+q)√n) 或 O(n√n)。

**核心代码**

```cpp
const int B = 450;
int bel[N], L[N], R[N], tag[N], a[N];

void build(int n) {
    int cnt = (n + B - 1) / B;
    for (int i = 1; i <= cnt; i++) {
        L[i] = (i - 1) * B + 1;
        R[i] = min(n, i * B);
        for (int j = L[i]; j <= R[i]; j++) bel[j] = i;
    }
}

void add(int l, int r, int x) {
    if (bel[l] == bel[r]) {
        for (int i = l; i <= r; i++) a[i] += x;
        return;
    }
    for (int i = l; i <= R[bel[l]]; i++) a[i] += x;
    for (int i = L[bel[r]]; i <= r; i++) a[i] += x;
    for (int i = bel[l] + 1; i < bel[r]; i++) tag[i] += x;
}

int query(int x) { return a[x] + tag[bel[x]]; }
```

**经典例题**

- 【模板】P3396 哈希冲突：按模数根号分治。
- 【模板】P3203 [HNOI2010] 弹飞绵羊：分块 + 块内跳转。
- 【进阶】P2801 教主的魔法：分块 + 块内排序二分。
- 【进阶】CF 13E Holes：分块/链接跳转。

**经典套路**

- 看到“区间加 + 单点查” → 分块/线段树/树状数组。
- 看到“模数很多，询问很多” → 根号分治。
- 看到“跳转/弹飞” → 分块维护跳出块的位置和步数。
- 看到“修改少、询问多” → 定期重构。
- 看到“出现次数少/多” → 按阈值分类。

**易错点**

- 块编号从 1 开始，`L[1]=1`，`R[cnt]=n`。
- 零散块不要重复加；整块标记不要漏。
- `B` 要按 n 调整，固定 450 只适合 n≈2e5。
- 分块 + 二分时，块内要保持有序；修改后重建该块。
- 根号分治的阈值要证明复杂度，不能随便取。

## 5.2 双指针

**算法思路** 当区间 `[l,r]` 的合法性关于 r 单调（r 越大越不合法，或越合法），就可以用双指针：右端点扩展，左端点收缩到合法为止。常见模型：

- 区间内不同数个数 ≥ k；
- 区间和 ≤ S；
- 最短/最长满足条件的子数组；
- 两个有序数组的合并/匹配。

关键是**证明单调性**：如果 `[l,r]` 不合法，那么 `[l,r+1]` 也不合法；否则不能直接双指针。

复杂度：O(n)（每个指针最多移动 n 次）。

**核心代码**

```cpp
int n, a[N], cnt[N];

int two_pointers() {
    int l = 1, ans = 0;
    for (int r = 1; r <= n; r++) {
        cnt[a[r]]++;
        while (l <= r && /* 不满足条件 */ false) {
            cnt[a[l]]--;
            l++;
        }
        ans = max(ans, r - l + 1);
    }
    return ans;
}
```

**经典例题**

- 【模板】P1638 逛画展：区间包含所有颜色，最短长度。
- 【模板】CF 701C They Are Everywhere：同类型，字符集。
- 【进阶】P3143 [USACO16OPEN] Diamond Collector S：排序 + 双指针。
- 【进阶】P1102 A-B 数对：排序 + 双指针/二分。

**经典套路**

- 看到“最短/最长满足条件的连续子数组” → 双指针。
- 看到“区间内不同数/出现次数” → 计数数组 + 双指针。
- 看到“两数之和/差” → 排序 + 双指针。
- 看到“固定右端点，左端点单调” → 直接维护。
- 看到“负数” → 前缀和不一定单调，慎用。

**易错点**

- 必须先证明单调性；有负数时“区间和 ≤ S”不单调。
- 收缩时先更新计数再移动 l，避免把当前元素删错。
- `l <= r` 的边界；空区间是否允许。
- 答案是长度还是方案数，更新时机不同。
- 多测清空计数数组。

## 5.3 反悔贪心

**算法思路** 贪心选当前最优，但允许“撤销”之前的选择。实现方式：

- **反悔堆**：先选，若超出限制就弹出代价最大的，相当于“撤销”；
- **链表 + 堆**：种树问题，选一个点后把左右合并成新点，权值为 `左+右-当前`，支持反悔；
- **时间倒流**：从后往前决策，把“删除”变成“加入”。

反悔贪心的正确性通常来自“拟阵”或交换论证；写之前先用小数据验证。

复杂度：O(n log n)。

**核心代码**

```cpp
struct Node { int d, len; } a[N];
bool cmp(Node x, Node y) { return x.d < y.d; }

ll scheduling(int n) {
    sort(a + 1, a + n + 1, cmp);
    priority_queue<int> q;
    ll t = 0;
    for (int i = 1; i <= n; i++) {
        t += a[i].len;
        q.push(a[i].len);
        if (t > a[i].d) {
            t -= q.top();
            q.pop();
        }
    }
    return (ll)q.size();
}
```

**经典例题**

- 【模板】P4053 [JSOI2007] 建筑抢修：按截止时间排序，反悔堆。
- 【模板】P2949 [USACO09OPEN] Work Scheduling G：工作调度。
- 【进阶】P1484 种树：链表 + 堆反悔。
- 【进阶】P1792 [国家集训队] 种树：环形版本。

**经典套路**

- 看到“最多选多少个，使总代价 ≤ 限制” → 反悔堆。
- 看到“选相邻不能选/环形” → 链表 + 堆合并。
- 看到“截止时间/收益” → 按时间排序 + 反悔。
- 看到“删除操作” → 时间倒流。
- 看到“费用流模型” → 反悔贪心往往是其特例。

**易错点**

- 反悔堆里存的是“代价”还是“收益”，大小根堆要分清。
- 超出限制时弹一个，不是弹到满足为止（按题目）。
- 链表合并后要更新左右指针和堆中的懒删除标记。
- 环形种树要特判全部选/首尾相邻。
- 反悔贪心不保证对所有题正确，先用暴力对拍。


# 第 6 部分 经典操作

这些不是独立算法，而是比赛中反复出现的“一句话结论/一个转化”。看到类似结构时，优先回忆这里。

## 6.1 树上两条路径是否相交

**结论** 设两条路径为 `(a,b)` 和 `(c,d)`，它们相交当且仅当：

$$
dis(a,b)+dis(c,d)=dis(a,c)+dis(b,d)
$$

或

$$
dis(a,b)+dis(c,d)=dis(a,d)+dis(b,c)
$$

直观理解：两条路径的长度之和等于“交叉连接”后的长度之和，说明它们在中间某处重合。

**核心实现**

```cpp
ll dist(int u, int v) {
    return dep[u] + dep[v] - 2LL * dep[lca(u, v)];
}

bool on_path(int a, int b, int x) {
    return dist(a, x) + dist(x, b) == dist(a, b);
}

bool intersect(int a, int b, int c, int d) {
    return dist(a, b) + dist(c, d) == dist(a, c) + dist(b, d)
        || dist(a, b) + dist(c, d) == dist(a, d) + dist(b, c);
}
```

**经典例题**

- 【模板】P3398 仓鼠找 sugar：判断树上两条路径是否相交。
- 【进阶】CF 1702G2 Passable Paths：判断点集是否在一条路径上。

**易错点**

- `dep` 是深度（边数），`lca` 要预处理；距离用 `long long`。
- 路径相交于端点也算相交；公式对端点成立。
- 树带边权时，`dep` 换成根到点的距离，公式仍成立。
- 不要用“两条路径的 LCA 相同”误判，反例很多。

## 6.2 gcd / & / | 只有 O(log V) 种变化

**结论** 固定右端点 r，以 r 结尾的所有子数组的 gcd（或按位与、按位或）只有 O(log V) 种不同值。因为每次变化至少让值除以 2（gcd）或减少一个二进制位（and/or）。

因此可以维护一个 `(值, 出现次数)` 的段列表，每次加入 `a[i]` 时合并相同值，统计答案。复杂度 O(n log V)。

**核心实现**

```cpp
vector<pair<int, int>> cur, nxt;
int n, a[N];

void solve() {
    for (int i = 1; i <= n; i++) {
        nxt.clear();
        nxt.push_back({a[i], 1});
        for (auto [g, c] : cur) {
            int ng = __gcd(g, a[i]);
            if (ng == nxt.back().first) nxt.back().second += c;
            else nxt.push_back({ng, c});
        }
        cur = nxt;
        // 此时 cur 是以 i 结尾的所有 gcd 段，按值合并
    }
}
```

**经典例题**

- 【模板】CF 475D CGCDSSQ：统计 gcd 等于 x 的子数组个数。
- 【进阶】P4310 绝世好题：按位与的最长 subsequence。
- 【进阶】CF 1614D1 Divan and Kostomuksha：gcd 分组 DP。
- 【进阶】P14221 学而时习之：前缀/后缀 gcd 变化 + ST 表。

**易错点**

- `gcd(0,x)=x`；初始化 `cur` 为空，第一段是 `a[i]`。
- 段列表要按值合并，不能按位置。
- 按位与/或把 `__gcd` 换成 `&`/`|`，单调性方向不同但段数仍 O(log V)。
- 统计答案时，每个段的长度是 `c`，不要只加 1。
- 多测清空 `cur/nxt`。

## 6.3 单点最远点是直径端点

**结论** 树上任意点 u 的最远点，一定是某条直径的端点。因此求“每个点的最远距离”只需：

1. 从任意点找最远点 A；
2. 从 A 找最远点 B；
3. 对每个 u，答案 = `max(dist(u,A), dist(u,B))`。

**核心实现**

```cpp
vector<pair<int, int>> g[N];
ll dis[N];

pair<int, ll> dfs(int u, int p) {
    pair<int, ll> res = {u, 0};
    for (auto [v, w] : g[u]) if (v != p) {
        auto [x, d] = dfs(v, u);
        d += w;
        if (d > res.second) res = {x, d};
    }
    return res;
}
// 第一次 dfs(1,0) 得 A；清空 dis 后 dfs(A,0) 得 B。
```

**经典例题**

- 【模板】P3304 [SDOI2013] 直径。
- 【模板】P4408 [NOI2003] 逃学的小孩：直径端点 + 次长链。
- 【进阶】CF 455C Civilization：动态维护森林直径。

**易错点**

- 边权有负时结论不成立；只能用树形 DP。
- 每次 DFS 前清空 `dis`；多测注意。
- 求的是“距离”还是“路径点数”，边权为 1 时差 1。
- 森林要分别找直径。

## 6.4 最值之间可构造中间值（Zero Path）

**结论** 对于一条**长度固定**的路径，如果路径和只能取某些离散值，且相邻路径可以通过局部交换连续变化，那么最小值和最大值之间的所有**同奇偶**值都能取到。典型题：网格中每次向右/向下，格子是 ±1，问是否存在和为 0 的路径。

做法：DP 求到达每个格子的最小和、最大和；若 `mn <= 0 <= mx` 且 0 与 `mn` 同奇偶，则存在。

**核心实现**

```cpp
const int M = 1005;
int a[M][M], mn[M][M], mx[M][M];

bool zero_path(int n, int m) {
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            if (i == 1 && j == 1) {
                mn[i][j] = mx[i][j] = a[i][j];
                continue;
            }
            int lo = INF, hi = -INF;
            if (i > 1) lo = min(lo, mn[i - 1][j]), hi = max(hi, mx[i - 1][j]);
            if (j > 1) lo = min(lo, mn[i][j - 1]), hi = max(hi, mx[i][j - 1]);
            mn[i][j] = lo + a[i][j];
            mx[i][j] = hi + a[i][j];
        }
    }
    return mn[n][m] <= 0 && 0 <= mx[n][m] && ((mn[n][m] & 1) == 0);
}
```

**经典例题**

- 【模板】CF 1695C Zero Path：网格 ±1，判断是否存在 0 路径。
- 【进阶】P1004 方格取数：两条路径 DP（不是同一模型，但常一起考）。
- 【进阶】CF 1695D? 树上路径和的可达性。

**易错点**

- 只适用于**固定长度**的路径；长度可变时中间值不一定连续。
- 奇偶性必须检查；`mn=-1, mx=1` 时 0 不可达。
- 初始化第一行/第一列；`INF` 要足够大。
- 网格下标从 1 开始，边界不要越界。

## 6.5 主席树维护区间不同数

**思路** 对每个前缀 `i` 建一棵位置线段树，只在“每个值最后一次出现的位置”放 1，其他位置放 0。查询 `[l,r]` 时，在 `root[r]` 上查询位置区间 `[l,r]` 的和，就是不同数个数。因为每个值只在最后一次出现处贡献 1。

等价离线做法：按 r 排序，树状数组维护最后一次出现位置；主席树可以强制在线。

**核心实现**

```cpp
int rt[N], lc[N * 40], rc[N * 40], sum[N * 40], tot;

void update(int &p, int pre, int l, int r, int x, int v) {
    p = ++tot;
    lc[p] = lc[pre];
    rc[p] = rc[pre];
    sum[p] = sum[pre] + v;
    if (l == r) return;
    int mid = (l + r) >> 1;
    if (x <= mid) update(lc[p], lc[pre], l, mid, x, v);
    else update(rc[p], rc[pre], mid + 1, r, x, v);
}

int query(int p, int l, int r, int ql, int qr) {
    if (ql <= l && r <= qr) return sum[p];
    int mid = (l + r) >> 1, res = 0;
    if (ql <= mid) res += query(lc[p], l, mid, ql, qr);
    if (qr > mid) res += query(rc[p], mid + 1, r, ql, qr);
    return res;
}

// 建树：last[a[i]] 为上一次出现位置
// rt[i] = rt[i-1];
// if (last[a[i]]) update(rt[i], rt[i-1], 1, n, last[a[i]], -1);
// update(rt[i], rt[i], 1, n, i, 1);
// last[a[i]] = i;
// 查询 [l,r]：query(rt[r], 1, n, l, r)
```

**经典例题**

- 【模板】P1972 [SDOI2009] HH 的项链：区间不同数。
- 【进阶】SP3267 DQUERY：同类型，多组询问。
- 【进阶】CF 703D Mishka and Interesting sum：区间出现偶数次的异或和。

**易错点**

- 每个前缀只保留最后一次出现，不是第一次。
- `update` 时 `pre` 是旧版本根，`p` 是新版本根，不要写反。
- 数组大小 `n log n`，主席树开 `N*40`。
- 查询区间是 `[l,r]`，不是 `[1,r]`。
- 多测清空 `tot` 和 `rt`。

## 6.6 线段树 push_up 维护带修 DP

**思路** 当 DP 的转移可以写成“矩阵/分段函数”，且需要单点修改时，把转移存在线段树节点里，`push_up` 合并两个区间的转移。查询根节点即可得到整个区间的 DP 值。典型例子：CF 750E 维护“包含 2017 且不包含 2016”的最小删除数；动态 DP 把树形 DP 的转移写成矩阵，重链剖分后用线段树维护。

**核心实现**

```cpp
struct Node {
    ll f[2][2];
};

Node merge(Node x, Node y) {
    Node z{};
    for (int i = 0; i < 2; i++)
        for (int j = 0; j < 2; j++) z.f[i][j] = -LINF;
    for (int i = 0; i < 2; i++)
        for (int k = 0; k < 2; k++) if (x.f[i][k] > -LINF)
            for (int j = 0; j < 2; j++)
                z.f[i][j] = max(z.f[i][j], x.f[i][k] + y.f[k][j]);
    return z;
}

Node t[N << 2];
void pushup(int p) { t[p] = merge(t[p << 1], t[p << 1 | 1]); }
```

**经典例题**

- 【模板】CF 750E New Year and Old Subsequence：线段树维护子序列自动机。
- 【进阶】P4719 【模板】动态 DP：树链剖分 + 矩阵。
- 【进阶】P4568? 分层图 + 线段树优化 DP。

**易错点**

- 合并顺序不能反；矩阵乘法不交换。
- 单位元要按运算定义：max-plus 是“对角线 0，其余 -INF”。
- 单点修改后要重新 `pushup` 到根。
- 状态数多时，矩阵大小要按实际状态开，避免超时/超内存。
- 动态 DP 的轻儿子贡献要先算好。

## 6.7 树上点/边贡献转二维数点

**思路** 子树在 dfs 序上是连续区间 `[tin[u], tout[u]]`。很多“祖先/子树/路径”限制可以转成二维偏序：

- 每个点看成 `(tin[u], val[u])`；
- 查询“子树内权值 ≤ x 的个数” → 矩形 `[tin[u], tout[u]] × (-∞, x]` 数点；
- 离线按 val 排序，树状数组维护 dfs 序。

典型：P3605 求每个点子树内权值比它大的个数；P3899 把“祖先/后代”限制转成二维数点。

**核心实现**

```cpp
vector<int> g[N];
int tin[N], tout[N], tim, bit[N];

void dfs(int u, int p) {
    tin[u] = ++tim;
    for (int v : g[u]) if (v != p) dfs(v, u);
    tout[u] = tim;
}

void add(int x, int v) {
    for (; x < N; x += lowbit(x)) bit[x] += v;
}

int sum(int x) {
    int s = 0;
    for (; x; x -= lowbit(x)) s += bit[x];
    return s;
}
// 子树查询：[tin[u], tout[u]]
```

**经典例题**

- 【模板】P3605 [USACO17JAN] Promotion Counting：子树内权值大于当前点。
- 【进阶】P3899 [湖南集训] 更为厉害：祖先/后代限制 + 二维数点。
- 【进阶】CF 383C Propagating tree：dfs 序 + 奇偶层。
- 【进阶】P3313 [SDOI2014] 旅行：树链剖分 + 动态开点。

**易错点**

- `tin/tout` 是 dfs 序，不是深度；子树区间是闭区间。
- 离线排序后，树状数组要按查询顺序回答。
- 边贡献要乘到子树的 `siz` 上；点贡献只算一次。
- 多测清空 `tim/bit`。
- 二维数点注意坐标范围，必要时离散化。

## 6.8 哈希 + 二分

**思路** 用滚动哈希 O(1) 求任意子串哈希，二分最长公共前缀（LCP）。常见用途：

- 判断两个子串是否相等；
- 求最长回文（正反哈希 + 二分/Manacher）；
- 比较两个后缀的字典序（LCP + 下一位）；
- 字符串周期/重复。

哈希冲突用双哈希或 64 位自然溢出；重要题目用确定算法。

**核心实现**

```cpp
const ull B = 131;
ull h[N], p[N];

void init(const string& s) {
    int n = s.size();
    p[0] = 1;
    for (int i = 1; i <= n; i++) {
        p[i] = p[i - 1] * B;
        h[i] = h[i - 1] * B + s[i - 1];
    }
}

ull get(int l, int r) {
    return h[r] - h[l - 1] * p[r - l + 1];
}

int lcp(int i, int j, int n) {
    int l = 0, r = n - max(i, j) + 1;
    while (l < r) {
        int mid = (l + r + 1) >> 1;
        if (get(i, i + mid - 1) == get(j, j + mid - 1)) l = mid;
        else r = mid - 1;
    }
    return l;
}
```

**经典例题**

- 【模板】P3763 [TJOI2017] DNA：允许最多 3 处不同，哈希 + 二分。
- 【进阶】P2870 [USACO07DEC] Best Cow Line G：哈希 + 贪心比较。
- 【进阶】P6739 [BalticOI 2014] Three Friends：哈希判断删除后相等。
- 【进阶】P3809 【模板】后缀排序：哈希 + 二分比较。

**易错点**

- 子串哈希公式是 `h[r] - h[l-1]*p[r-l+1]`，下标从 1 开始。
- 自然溢出用 `unsigned long long`，不要用有符号。
- 二分的 `r` 上界是 `n-max(i,j)+1`，不是 n。
- 双哈希要同时比较两个模数。
- 哈希 + 二分是 O(log n)，但常数不小；能 Manacher/Z 就用确定算法。

## 6.9 线段树区间加法优化 DP（Bakery）

**思路** 以 CF 833B The Bakery 为例：把序列分成 k 段，每段价值为不同数个数，最大化总价值。DP：

$$
f[i][j]=\max_{t<j}\{f[i-1][t]+distinct(t+1,j)\}
$$

固定 i，从左到右扫 j，用线段树维护每个 t 的 `f[i-1][t]+distinct(t+1,j)`。当 j 向右移动时，只有“上一个出现位置”到 j-1 的 t 的 distinct 增加 1，用区间加；查询全局 max。

**核心实现**

```cpp
ll mx[N << 2], tag[N << 2];

void apply(int p, ll v) {
    mx[p] += v;
    tag[p] += v;
}

void pushdown(int p) {
    if (tag[p]) {
        apply(p << 1, tag[p]);
        apply(p << 1 | 1, tag[p]);
        tag[p] = 0;
    }
}

void update(int p, int l, int r, int ql, int qr, ll v) {
    if (ql <= l && r <= qr) {
        apply(p, v);
        return;
    }
    pushdown(p);
    int mid = (l + r) >> 1;
    if (ql <= mid) update(p << 1, l, mid, ql, qr, v);
    if (qr > mid) update(p << 1 | 1, mid + 1, r, ql, qr, v);
    mx[p] = max(mx[p << 1], mx[p << 1 | 1]);
}
```

**经典例题**

- 【模板】CF 833B The Bakery：分成 k 段，最大化不同数之和。
- 【进阶】CF 474E Pillars：线段树优化 DP（不是区间加，但同思路）。
- 【进阶】P4072 [SDOI2016] 征途：斜率优化/线段树。

**易错点**

- 每层 DP 开始前，线段树要按 `f[i-1][t]` 重建。
- 区间加的范围是“上一次出现位置到 j-1”，不是到 j。
- 查询的是全局 max，不是区间 max。
- 滚动数组/清空 tag；多测注意。
- 复杂度 O(k n log n)，k 大时会超时，需优化。

## 6.10 左闭右开的处理

**结论** 统一使用左闭右开 `[l, r)` 可以消除大量 `+1/-1` 错误：

- 区间长度 = `r - l`；
- 空区间 = `l == r`；
- 差分：`[l, r)` 加 x → `d[l] += x, d[r] -= x`；
- 线段树递归：`[l, mid)` 和 `[mid, r)`，判断 `ql < mid`、`mid < qr`；
- `lower_bound` 返回第一个 ≥ x 的位置，天然是左闭右开。

**核心实现**

```cpp
int d[N];

void diff_add(int l, int r, int x) {
    d[l] += x;
    d[r] -= x;
}

void update(int p, int l, int r, int ql, int qr, int v) {
    if (ql <= l && r <= qr) {
        // apply
        return;
    }
    int mid = (l + r) >> 1;
    if (ql < mid) update(p << 1, l, mid, ql, qr, v);
    if (mid < qr) update(p << 1 | 1, mid, r, ql, qr, v);
}
```

**经典例题**

- 【模板】P2367 语文成绩：差分数组。
- 【模板】P3372 【模板】线段树 1：区间加/区间和。
- 【进阶】ICPC 杭州 2024 E. Elevator II：区间操作 + 左闭右开。
- 【进阶】P1904 天际线：左闭右开扫描线。

**易错点**

- 差分数组要开到 `n+1`，`d[r]` 可能等于 n。
- 线段树叶子区间是 `[i, i+1)`，不是 `[i, i]`。
- 递归条件 `ql < mid` / `mid < qr` 与闭区间不同。
- 答案查询 `[0, n)` 不要漏最后一段。
- 离散化后区间端点要统一。

# 第 7 部分 注意事项与赛前检查

这一部分是把“会做”变成“能过”的最后一公里。建议赛前 5 分钟快速扫一遍 7.7。

## 7.1 空间与初始化

- 全局数组按最大数据范围开；一般 `N = 2e6 + 5` 是保险值，但提交前仍要按题面核对。
- 图论无向边开 `2*M`，线段树开 `4*N`，主席树开 `N*40`，虚树开 `2*N`。
- `vector` 开数组用 `vector<int> a(n + 5, 0)`；直接 `a[n]` 会越界。
- 变量名：局部变量/循环变量不要遮蔽全局变量；`k`、`x`、`n` 最容易重名，提交前扫一遍。
- 下标越界：`<0` 和 `>=N` 都要提前判断；`lower_bound` 返回 `end()` 时不要直接解引用。
- 递归深度大时开栈：`-Wl,--stack=268435456`；或改迭代。
- 多测时全局数组、`vector`、`set/map`、邻接表都要清空。
- `memset` 只能按字节设置；`double` 数组用 `fill`，不要 `memset(0x3f)`。
- `fill(v.begin(), v.end(), 0)` 比 `memset` 更适合 `vector`。

## 7.2 多测清空

- 每个数组挨个检查：`dfn/low/vis/fa/siz/head/tot/tim/top`。
- STL 容器：`vector.clear()`、`set.clear()`、`priority_queue` 重新构造。
- 全局计数器：`tot/tim/cnt/ans` 清零。
- 图论：`head` 清空，`tot` 从 1 开始；边数组不用完全清，但 `head` 必须清。
- 多测的 `solve()` 里定义局部变量，减少清空遗漏。

## 7.3 整数与溢出

- `int` 约 2e9；`long long` 约 9e18；答案、距离、方案数优先 `long long`。
- `#define int long long` 是保险操作，但会让 `printf("%d")`、`abs`、`max`、内存全部变大；提交前确认。
- 乘法前转 `long long`：`1LL * a * b`；必要时 `__int128`。
- `mid = (l + r) >> 1` 可能溢出，写 `l + (r - l) / 2`。
- `size_t` 是无符号，`v.size() - 1` 在空容器会下溢；比较时先转 `int`。
- 输出 `long long` 用 `%lld` 或 `cout`；`__int128` 要自己写输出。
- 模运算减法：`(x % MOD + MOD) % MOD`。

## 7.4 浮点与精度

- 算法竞赛一般用 `double`（15 位有效数字）即可；`long double`（18 位）在卡精度时再用。
- `printf("%.10f\n", ans)` 输出稳定；`double` 用 `%f`，`long double` 用 `%Lf`。
- 注意 `-0.00`：极小负数格式化后会输出 `-0.00`，输出前加 `if (fabs(ans) < eps) ans = 0;`。
- 比较浮点用 `fabs(a - b) < eps`，不要用 `==`。
- 能用乘法比较就不用除法：`a/b < c/d` → `a*d < c*b`，注意溢出用 `__int128`。
- 几何题优先整数叉积；必须浮点时用 `long double` + `eps`。

## 7.5 STL 与迭代器

- `multiset` 删除一个元素：`s.erase(s.find(x))`；直接 `s.erase(x)` 会删掉所有等于 x 的。
- `set` 遍历中删除：`it = s.erase(it)`（C++11 返回下一个迭代器）；或 `s.erase(it++)`。
- `map` 的 `operator[]` 会插入默认值；查询用 `find`。
- `priority_queue` 默认大根堆；小根堆用 `greater<int>` 或存负值。
- `unordered_map` 可能被卡；用自定义哈希 + `reserve`，或改 `map`。
- `vector` 扩容会使指针/迭代器失效；需要稳定地址时先 `reserve`。
- `std::function` 递归有开销；必要时用 lambda + `auto&& self`。

## 7.6 图论/树常见坑

- 无向图重边：割边/割点要用边编号，不能只记父节点。
- 自环：SCC/最短路/生成树要按题目处理；矩阵树要去掉自环。
- 负权：Dijkstra 不能用；用 SPFA/Bellman-Ford/Johnson。
- 不连通：多棵树要分别 DFS；虚树要建虚根。
- 1-index/0-index：输入、数组、输出统一；字符串 KMP 用 0-index。
- 递归深度：链状树可能 1e5，开栈或改迭代。
- 多测：`head`、`dfn`、`vis`、`tot` 都要清。
- 双向边：正反边编号 `i` 和 `i^1`，`tot` 从 1 开始。

## 7.7 赛前 5 分钟检查表

void dfs_lca(int u, int p) {
    dep[u] = dep[p] + 1;
    up[0][u] = p;
    for (int k = 1; k < 20; k++) up[k][u] = up[k - 1][up[k - 1][u]];

## 1. 准备工作

你电脑上已经有一份网站文件了（就是你现在看的这个文件夹）。

文件夹里面有这些东西：

```
blog/
├── index.html          ← 主页（博客列表）
├── about.html          ← 关于页面
├── style.css           ← 样式文件（控制颜色和排版）
├── posts/
│   └── hello-world.html  ← 第一篇示例文章
└── README.md           ← 你正在看的说明文档
```

> 💡 **你需要准备的东西**：Google Chrome 浏览器（推荐，任何浏览器都行） + 你的 GitHub 账号密码。

## 2. 在 GitHub 创建仓库

> 🎯 **目标**：在 GitHub 上创建一个"仓库"。仓库就是你放代码的地方，可以理解为一个网盘文件夹。

### 一步一步来：

**第 1 步**：打开浏览器，访问 [github.com](https://github.com)，登录你的账号。

**第 2 步**：登录后，在页面右上角点击 **"+"** 号，然后选择 **"New repository"**（新建仓库）。

> 如果找不到 "+" 号：看页面右上角，你的头像旁边。点击后会弹出一个菜单。

**第 3 步**：填写仓库信息：

| 填写项 | 填什么 |
|--------|--------|
| Repository name（仓库名） | **你的用户名.github.io** |
| Description（描述，选填） | 我的个人博客 |
| Public / Private | 选 **Public**（公开，免费） |
| Add a README file | **不要勾选** ❌ |

> ⚠️ **重要**：仓库名必须是 `你的用户名.github.io` 这个格式！
>
> 比如你的 GitHub 用户名是 `tianyi123`，仓库名就填 `tianyi123.github.io`
>
> 只有这样才能用 GitHub Pages 功能。

**第 4 步**：点击页面底部的绿色按钮 **"Create repository"**（创建仓库）。

✅ 完成！你现在有了一个空的 GitHub 仓库。

## 3. 上传文件到 GitHub

> 🎯 **目标**：把电脑里的网站文件传到刚创建的 GitHub 仓库里。

**第 1 步**：在刚创建的仓库页面，你会看到一堆文字。找到蓝色的链接 **"uploading an existing file"**（上传已有文件），点击它。

> 如果没有看到这个页面，找一下页面上有没有 **"upload"** 相关的链接或按钮。

**第 2 步**：你会进入一个文件上传页面。

- 先把 `index.html`、`about.html`、`style.css` 这三个文件**拖拽**到网页中间的框里。
- 然后创建一个文件夹放文章：在页面里找到 **"Create new file"** 的地方，或者先在电脑上整理好。

> 💡 **更简单的做法**：直接在电脑上，把整个 `blog` 文件夹里的内容，拖到这个页面上传框。GitHub 会自动识别文件夹结构。

**第 3 步**（上传 posts 文件夹里的文章）：
- 如果上一步拖拽了整个文件夹，posts 应该已经在里面了。
- 如果没看到 posts 文件夹，在页面上点击 **"Add file"** → **"Create new file"**，在文件名那里输入 `posts/hello-world.html`（注意要加斜杠），然后把 [posts/hello-world.html](posts/hello-world.html) 的内容复制粘贴进去。

**第 4 步**：页面往下滑，在 **"Commit message"**（提交信息）那里，可以写一句说明，比如 "第一次上传网站文件"。

**第 5 步**：点击绿色按钮 **"Commit changes"**（提交更改）。

✅ 完成！文件已经传到 GitHub 仓库了。

## 4. 启用 GitHub Pages

> 🎯 **目标**：让 GitHub 把你的文件变成可以访问的网站。

**第 1 步**：在仓库页面顶部，点击 **"Settings"**（设置）标签页。

**第 2 步**：在左侧菜单中，找到并点击 **"Pages"**。

**第 3 步**：在 "Branch"（分支）下面，有一个下拉菜单。确保选的是 **"main"**，旁边选 **"/ (root)"**，然后点击 **"Save"**。

**第 4 步**：等待 1-2 分钟，刷新页面。你会看到一行字：

> "Your site is live at https://你的用户名.github.io/"

**第 5 步**：点击那个链接，你的网站就上线了！🎉

> 🔗 在手机、平板、任何电脑上都能访问这个网址。

## 5. 以后怎么添加新文章

这是最重要的部分——学会这个，你就能不断更新博客了。

### 方法很简单（总共 4 步）：

**第 1 步**：复制模板文件

在 GitHub 仓库里，点进 `posts/` 文件夹，找到 `hello-world.html`，点进去。然后：
- 点击右上角的复制图标（或 "Copy raw" / "Raw" 按钮）
- 回到仓库主页，点击 **"Add file"** → **"Create new file"**
- 文件名输入：`posts/我的新文章.html`（用英文或拼音命名，不要用中文）
- 把复制的内容粘贴进去

**第 2 步**：修改文章内容

在粘贴的内容里：
- 修改 `<h1>` 里的文章标题
- 修改 `.article-meta` 里的日期
- 修改 `<div class="zh">` 里的中文内容
- 修改 `<div class="en">` 里的英文内容
- 标题改 `<title>` 标签里的文字

**第 3 步**：在主页面添加文章链接

打开 `index.html`，点击右上角的 ✏️（编辑按钮）。
找到文章列表部分（`<ul class="post-list">` 和 `</ul>` 之间），复制一段 `<li class="post-card">...</li>` 的代码，修改：
- 文章链接（`href="posts/我的新文章.html"`）
- 标题
- 日期
- 摘要

**第 4 步**：提交更改，等 1-2 分钟，刷新你的网站就能看到新文章了。

## 6. 怎么修改网站内容

| 想改什么 | 改哪个文件 | 怎么改 |
|----------|-----------|--------|
| 网站标题/介绍 | `index.html` | 找到 `<header class="hero">` 部分，改里面的文字 |
| 关于页内容 | `about.html` | 找到 `<div class="about-section">` 部分 |
| 网站颜色 | `style.css` | 找到文件顶部的 `:root { ... }`，改颜色值 |
| 删除文章 | 删掉 `posts/` 里的文件 + 删掉 `index.html` 里对应的卡片 |

### 改颜色的说明：

打开 `style.css`，最顶部你会看到：

```css
:root {
  --accent: #c77d4b;     /* 强调色：标题、链接的颜色 */
  --bg: #fefaf6;          /* 背景色 */
  ...
}
```

把 `#c77d4b` 换成你喜欢的颜色就行。比如：
- 蓝色：`#4a90d9`
- 绿色：`#5a9e6f`
- 紫色：`#8b5cf6`

> 🌐 **查颜色**：在 Google 搜 "color picker"，可以自己调颜色，然后复制那个 `#` 开头的值。

## 🆘 遇到问题？

- 上传后网站没更新？等 1-2 分钟，GitHub Pages 需要时间处理。
- 网站显示不对？检查文件名是否完全一致（大小写也要对）。
- 完全搞不懂？把错误截图发给懂的朋友帮忙看看。

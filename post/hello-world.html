This is my very first blog post. 🎉

Why start a blog?

I've always wanted a little corner of the internet to write down thoughts and things I learn. Rather than scattering notes everywhere, putting them on a website helps me review them — and maybe helps others too.

How was this site built?

This site is super simple — just HTML + CSS, hosted on GitHub Pages (free). No complicated frameworks or tools. It just works.

I chose GitHub Pages because it's free, reliable, and zero-maintenance. Whenever I add a new post to the repo, the site updates automatically.
